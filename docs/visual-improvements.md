# 0.3.1-dev 画面改进记录

本轮根据用户对 0.3.0-dev 实机画质的反馈，继续以已认可的林恩角色和森林概念图为方向。目标是改善实际可游玩场景的材质、构图和角色精细度。概念图仍是设计参考，不能用它代替新版游戏截图。

## 对照基准

- 实际地图：M01 村外林径，角色位置 `(-5, 4)`，1280×720，相同开场任务状态。
- 旧版实际截图保留为 `builds/visual-before-M01.png`；村庄用原0.3.0发行PCK重新采集 `builds/visual-before-M00-matched.png`，和新版同为 `(-8,5)`，没有把不同位置当作同位置比较。
- 两版均为1280×720。森林新版镜头由12.4调整为10.8，靠近人物以让角色细节更清楚；村庄保持12.4。比较展示了本轮镜头改动，不能当作固定倍率的贴图分辨率测量。
- 已检查森林、村庄、雾泽与终章，以及低画质模式中的交互和攻击预告可读性。

## 本轮画面问题与验收方向

| 旧版问题 | 本轮验收方向 |
| --- | --- |
| 地面大块纯色和明显菱形格，细节只靠稀疏小草 | 苔土、碎叶、石屑与土路有可辨的材质；路缘自然，主路保持清楚 |
| 树木细节与几何松树、房块、积木式人物不统一 | 统一冷暖色调与细节密度；角色有独立细化的面部、披风与铜灯 |
| 森林大片空地，缺少地标与空间层次 | 沿现有可通路径布置可读的木石地标，形成前、中、后景层次 |
| 灯火发亮却缺少暖色落地，圆形黑影显得悬浮 | 人物和灯柱周围有暖色光落地，物体接地阴影更自然 |
| 两大 HUD 卡和常驻网页式按钮压缩场景 | 保留可读字号与操作入口，使用紧凑的 RPG HUD，让场景露出更多 |

## 范围与验证记录

完成的实际改动：

- 林恩原生64×96，四方向八动作、156姿态；攻击和闪避按自身计时顺序播放。不是放大旧32×48精灵。原稿、脚锚和来源见[角色资料](../assets/art/characters/lynn_hd/README.md)。
- 苔土、灰褐土路和石材采用512×512原创可重复纹理，按3.5–5世界单位重复；草、蕨、灌木和碎叶形成路缘、树根与溪岸叶群。村庄共用地表流程，路线使用石材。来源见[环境资料](../tools/environment-art-provenance.md)。
- 森林主路与细支路区分，M01现有可走路加入浅溪、岸石、低木桥和灯柱；桥面木纹与房屋石墙/木构细节来自项目内原创绘制。
- 林恩附近的地表落光采用柔边琥珀色，灯柱照亮局部木石；阴影与植被形成接地关系。Standard采用2x MSAA改善三维边缘，Low关闭；人物精灵保持nearest以保持像素形状。
- HUD资源栏紧凑排列，目标只保留关键文字，小地图与轻量按钮移到右下；18px以上常规文字及125%字号经过界面检查。

最终实际渲染：`builds/gameplay.png`、`village-031.png`、`forest-no-hud-031.png`、`marsh-031.png`、`sanctuary-031.png`。无HUD图通过同一实际场景暂时隐藏界面采集，没有对截图做后期修饰。

本次完整源码检查通过：Campaign148、Progress42、Content1645、Puzzles1143、World15图及Scene295。场景代理另完成真实GL Compatibility十五图检查；发行PCK从仓库外加载并完成14/14菜单、移动与存读档检查。独立程序的最终验收见[运行记录](verification.md)。

这些是实际开发版画面改进。NPC、敌人与部分建筑仍保留开发素材，未声称整个游戏已达到概念插画的完成度。首次游玩时长、Windows实机、声音设备与商业美术精修仍需独立验收。
