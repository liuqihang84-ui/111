# 演示配乐与音效来源

本项目的 `assets/audio/*.wav` 是根据项目原创旋律、和弦编排与合成参数生成的演示音频。没有使用外部录音、商业音源、下载素材、第三方 MIDI 或现成歌曲。音色由正弦及泛音、包络、轻微噪声和延迟组成；它们模拟柔和钟琴、木管、暖弦、低音和轻敲击，不是真实乐器的专业录音。

旋律、合成工具和 WAV 均在本项目制作过程中由开发助手编写或生成。它们可随《暮光之森》项目使用、修改、分发与发布，不需要标注第三方音频作者。此说明记录素材来源和项目使用意图；AI 辅助生成内容在不同地区的著作权地位可能不同，不声称获得第三方授权或独占版权。

## 可重制的来源

生成工具：[tools/generate_audio.py](../../tools/generate_audio.py)。完整文件元数据：[assets/audio/manifest.json](../../assets/audio/manifest.json)。

重新生成需要 Python 3 和 NumPy；执行 `python3 tools/generate_audio.py`。固定随机种子 `20261003` 使噪声与音色可重复。游戏运行不需要 Python 或 NumPy，也不在主线程动态合成音频。

配乐的音符尾音与延迟跨循环边界包裹，避免硬切尾音。运行时用两个 `AudioStreamPlayer` 交叉淡入淡出，并用独立音效声部播放操作反馈。音量为 0 时静音两个专用总线，音效和配乐都停止输出声音。

“遗迹调音”的低、高、中音使用同一原创 `sfx_interact.wav`，以 0.75、1.5、1.0 的播放倍率产生不同音高，不增加外部音源。提示物同时显示音区名称，主音量为零时仍可读线索。
