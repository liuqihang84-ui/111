# 《暮光之森》全流程内容制作记录

用户已授权恢复设计与游戏编码。本文件是本轮内容实现的契约与实况，替代旧文档中“开发暂停”的阶段描述；旧策划中的人物、十五地图范围、五章与固定结局继续采用。设计来源为 `game-design.md`、`story-and-world.md`、`gameplay-systems.md` 与 `art-direction.md`。

## 内容实现范围

`scripts/campaign_data.gd` 提供可直接被 Godot 运行时加载的数据，包含五章十五图、十种普通敌人、五名 Boss、八个支线、六枚护符、阿芙／小禾／岑灯三名 NPC、逐图叙事与最后的完整结局文字。人物与主要事件采用原策划，逐对象对白与调查文字为本轮原创。

数据实现不等于全部游戏功能已经验收：场景、交互、战斗、任务、奖励、商店、菜单、保存与发行包由运行时代码接入这些数据。需要以真实通关与存读档验证接入结果，不把数据条目数量当作功能验证。

主线 **5–7 小时、最低五小时**仍是目标，尚未经过真实首次试玩验证。本轮不会用强制等待、增加 Boss 血量、重复刷怪或故意增加往返来宣称满足时长。当前数据已经覆盖完整故事顺序；要达到原定 310–405 分钟，需要真实试玩按章统计探索、对话、机关、战斗与重复尝试，再补充具有发现和玩法变化的内容。可选探索 7–10 小时同样未经验证。

## 可运行数据接口

| 接口 | 返回内容 |
| --- | --- |
| `map_count()` | 固定为 15 |
| `map_data(id)` | 地图字典；非法编号返回空字典 |
| `maps()` | 按 M00–M14 顺序排列的地图字典数组 |
| `enemy_data(type)` | 对应敌种数值与行为；未知键返回空字典 |
| `charms()` | 六枚固定护符的显示名、说明、价格与效果 |
| `side_quests()` | 八个支线的对象依赖与一次性奖励 |

地图字典使用地面 `Vector2` 坐标，运行时对应三维场景的 X/Z 平面。每个地图独立记录 `bounds`、入口、篝火、出口、树木和圆形实体障碍。对象、敌人和 Boss 的 ID 在全流程中唯一，可用于永久状态与存档。接口返回深拷贝，运行时修改不会污染内容原表。

地域键为 `village/forest/marsh/ruins/city/sanctum`。地图的尺寸从村庄的 40×30 单位到根庭的 64×48 单位不等，主路和物件位置人工安排；树木框景与少量内部树岛由确定性布局补充。布局保留中央通行带，避开出生、篝火、出口、交互、敌人与 Boss 场地。所有物件位于地图边界内，不依赖无限地图或随机地牢。

对象类型固定为 `npc/note/lamp/crystal/lens/rune/shield/anchor/chest/side/camp`。`required` 列表只存当前地图的主线对象 ID，下一出口还应检查本图 Boss 的永久胜利状态；支线与宝箱不作为主线门槛。

对象可有能力门槛 `ability`，只使用 `pulse/lens/echo/shield`。`reward` 是字典，可记录 `coins/potions/charm/ability`；能力奖励的物件不要求先持有同一能力。本轮接入规则需要实际操作：光脉冲门在脉冲生效时交互；透镜与回响物件需举灯；护罩门在护罩生效时交互。持有能力本身不能代替动作。

`rune.order` 是规则引擎使用的私有连续顺序。M08、M09、M12 的对象数组刻意不是答案顺序，玩家看见火／水／根、岸／库／返门、门／窗／钟纹样，再从对应记录推断关系；标题没有答案编号。选错可以立即重试，不消耗主线物件。可选调音物件使用 `side` 类型，避免与主线符文顺序混淆。

所有透镜门槛对象带 `hidden = true` 与 `reveal_radius = 4.0`。首次发现要求持有透镜、举灯且在四单位内；完成后可永久看见并重读。未发现目标不应从世界标牌、地面影子、指路连线或小地图泄露位置。线索记录仍指明搜索依据，隐藏不是随机点击空地。

## 中后期 Boss 的二十条状态规则

以下是本轮采用的具体机制，不以提高血量替代玩法。数据提供节点 ID、纹样、位置与阶段说明，模型负责即时状态、伤害、窗口与重置。节点是战斗中可重复连接的临时构件，不计入主线永久物件，不会因某次交互后无法再次破解。

铭文守像三节点位于 `(7,-8)/(12,-3)/(17,-8)`，分别是岸纹／库纹／返门纹；Data 的 `node_order = [0,1,2]` 表示每轮开放的次序。

| 步骤 | 状态与触发 | 预告与破解 |
| --- | --- | --- |
| 守像 1 | 休眠；本图必需任务完成且林恩进入七单位范围后唤醒 | 先给完整攻击预告，不从休眠直接落伤；前厅可以先读完整记录 |
| 守像 2 | 护核闭合；初始化或六秒窗口结束 | 外部纹样成为当前目标，剑与脉冲不能越过护核；核心闭合有状态文字 |
| 守像 3 | 石纹警告锁定林恩当时的位置 | 两单位地面震圈显示实际落点，不随玩家转向追踪；离开圈即可避开 |
| 守像 4 | 预告结束，震圈落伤 | 单次攻击最多命中一次；提前闪避或移出震圈，不能在同一帧反复受伤 |
| 守像 5 | 落伤后进入约 2.2 秒恢复 | 石身停止追加攻击；利用这段时间靠近亮起的端点，不需贴身硬换血 |
| 守像 6 | 首轮岸纹亮起，后续按岸→库→返门循环 | 三枚外部纹样不是沿地图数组走；当前可用节点发光，其余仍可辨认 |
| 守像 7 | 距当前节点不超过 1.8 单位，举灯并以回响灯芯交互 | 正确连接解除护核；错节点只提示“回流未到”，不消耗材料、不给永久错误标记 |
| 守像 8 | 连接成功，核心开放六秒 | 下一次落伤前再给至少约 1.4 秒清楚预告；玩家可选择回核心攻击或先躲开危险 |
| 守像 9 | 六秒结束且 Boss 尚未解除 | 核心闭合，临时完成标记清空，下一纹样接管；单轮没有打完就再次破解，不形成软锁 |
| 守像 10 | 生命归零，错误识别解除 | 永久记 Boss 胜利、一次奖励与章末对白；死亡重试重建临时轮次，但已完成主线调查仍保留 |

暮根之心三节点位于 `(9,-8)/(14,-3)/(19,-8)`，分别是回流纹／灯芯纹／外根纹。阶段二 `node_order = [2,0,1]` 对应外根→回流→灯芯；阶段三真实接头是中间灯芯纹。人物不是向古树提供生命，玩家调通的是守灯构件。

| 步骤 | 状态与触发 | 预告与破解 |
| --- | --- | --- |
| 根心 1 | 完成本图主线并进入场地，根环阶段开始 | 状态说明“靠近结光以光脉冲放慢”，首攻先显示危险形状；不授予第五种能力 |
| 根心 2 | 护核闭合，交替蓄出根环或三线扇形 | 根环显示圆形范围；扇形锁定方向，三条长十单位、半宽约 0.65 的真实伤害线与预告对应，可从夹缝移动 |
| 根心 3 | 第一阶段生命高于三分之二，林恩在核心 1.8 单位内释放脉冲 | 脉冲放慢结光并打开五秒窗口；先判断攻击空档再靠近，不要求站着承受根环 |
| 根心 4 | 第一阶段五秒窗口结束 | 核心重新闭合，可在能力自然恢复后再次脉冲；灯能会恢复，不用刷怪取得关键钥匙 |
| 根心 5 | 生命跨过三分之二，转入回流阶段 | 两秒安全转场取消上一段伤害并清空临时节点；林恩仍可移动，提示外根→回流→灯芯 |
| 根心 6 | 回流阶段举灯回响，按外根、回流、灯芯依次交互 | 纹样与故事中的光旅行一致；错端点只给方向反馈，不耗材料、不丢已读记录，可立即继续尝试 |
| 根心 7 | 三节点全连通，核心开放七秒 | 给新的完整攻击预告再落伤；窗口结束清除临时接线，可再次连接，不把永久机关标记误用为战斗锁 |
| 根心 8 | 生命跨过三分之一，转入稳定阶段 | 再给两秒安全转场；透镜加举灯显出真实灯芯接头，假外壳不发出相同的激活提示 |
| 根心 9 | 看清真实灯芯，在护罩生效时近距交互 | 护罩保护连接动作而不是要求额外收集装备；正确稳定打开七秒窗口，护罩用完可自然恢复后重试 |
| 根心 10 | 核心解除，调光稳定 | 战斗与伤害停止，导师生还、古树保留、灯塔修复进入完整结局；可选落叶或纸鹤只作纪念，不改变结局资格 |

其余三名 Boss 也分别承担学习阶段：归灯守卫教玩家离开震圈与利用恢复期；雾泽巡猎者按预告锁定短冲刺路径，侧移后等待停步；巡夜者先剑扫、再独立预告枪刺，不能把第一段结束误作完整空档。上述运行时机制由 `campaign_model.gd` 接入，最终仍需真人检验预告在相机、特效与实际操作下是否清楚。

## 支线、奖励与经济

支线依赖跨图稳定对象 ID；`map_id` 是所属地域或第一处任务地点，不意味着所有物件都在同图。六条探索支线收齐 `object_ids` 后结算一次；调音与核账另需完成相应推理，收集标记不能直接结算。回访、读档和重复交互不能复制奖励。八条支线均不影响主线通行与导师生还。

| 支线 | 地图 | 本轮可运行奖励 |
| --- | --- | --- |
| 重燃旧灯 | M01 | 18 灯屑 |
| 迷路孩子 | M01、M02 | 12 灯屑、林行叶 |
| 雾泽路标 | M04 | 20 灯屑 |
| 沉灯回收 | M05、M06 | 22 灯屑、澄光石 |
| 石匠留言 | M07、M09 | 24 灯屑 |
| 遗迹调音 | M09 安全前厅；M08 留教学记录 | 20 灯屑、回响环 |
| 旧城账册 | M10、M11 | 30 灯屑 |
| 树下约定 | M13 | 28 灯屑、完整约定文字 |

这是本轮明确采用的奖励表。旧世界文档中的一次药品免单、据点灯架变化、篝火短曲和账册永久折扣仍是表现增强目标，当前数据没有把它们声明为已完成。树下约定的收集在 M13 结算，M14 结局对白保证导师生还；不把可选支线完成作为结局门槛。

本轮把两条支线做成真实的听音／推理任务，其余六条保持探索与调查骨架，不宣称八种互不相同的玩法。具体差异如下：

| 支线 | 玩家实际发现与动作 | 叙事回馈与范围 |
| --- | --- | --- |
| 重燃旧灯 | 林径同图三次维修调查，没有后期能力门槛 | 石凳、小溪、回程三种用途说明灯为何保留；属于基础交互收集 |
| 迷路孩子 | 跨 M01/M02 检查反向箭头、找到小禾、辨认纸鹤中的正确入口 | 孩子把“从家里看的方向”纠正成回程方向；没有模拟跟随护送，小禾安全由对白交代 |
| 雾泽路标 | 用已学光脉冲激活三处岸线标记 | 水位与距离的区别、运灯者停靠点、归渡方向；仍为三节点能力交互，不是可旋转路标谜题 |
| 沉灯回收 | 跨 M05/M06 举灯透镜近距显出三盏可回收灯 | 铜框、灯芯、屋檐分别证明旧物可修；无需潜水，也没有危险水下采集系统 |
| 石匠留言 | 跨 M07/M09 比较三页拓印，补全闭门仍保留出口的原意 | 对照主线对“供灯者”的误读；目前不会要求玩家另做排列答题 |
| 遗迹调音 | 在同图试听／连接低、中、高三灯，按低→高→中顺序完成 | 高音把声音送远，中音接住回响；真正序列判定与三音反馈，不要求精确拍点 |
| 旧城账册 | M10/M11 取得三页证据，再找阿芙回答三个数量选项 | 六盏中三盏回工坊、两盏返屋檐、一盏留街口，留当地正确为三；真正问答判定 |
| 树下约定 | 在根庭找出学灯、回家、未受损落叶三份记忆 | 导师不是替林恩做好所有事，而是留出重试空间；可选纪念物不改变单一结局 |

调音数据 `mechanic = tone_sequence`、`sequence = [m08_music_a, m09_music_c, m08_music_b]`，三个稳定 ID 保留，但位置统一迁至 M09 前厅。对象分别带 `tone = low/mid/high`、`tone_title`、`repeatable = true`；低、高、中可从文字辨认，静音也可完成。每次交互发出 `tone_low/tone_mid/tone_high` 音频事件。错序免费重试，临时演奏进度在离图后重置；已完成的任务与奖励永久保存，不需跨图保存半首曲子。

核账数据 `mechanic = ledger_choice`、`finish_npc = afu`，提供三个 `{id, text}` 选项，唯一正确 `correct_choice = three`。三页齐全后任务为“待核对”，任何地图的阿芙都可发出问答；不强迫走回 M10。运行时 `dialogue_choices` 交给 UI，选择调用 `choose_choice(id)`；错答不扣货币，可继续看解释再答，正确答案才一次性授奖。问答是可选任务，不会占用唯一通关出口。

六护符的数值沿用系统草案，价格为 25/30/30/35/40/35 灯屑。归灯结可在 M01 宝箱找到，林行叶、澄光石、回响环由三条对应支线获得，守夜扣在 M11 宝箱，温火坠可向阿芙购买。固定取得与商店售卖应检查拥有标记，不能重复增加同一护符效果。

恢复药的建议商店价为 8 灯屑。普通宝箱提供固定货币与补给，重要能力不出售、不消耗、不占可丢弃库存。商人只使用同一个阿芙身份，在 M00、M04、M07、M10 以不同对白出现；岑灯直到 M14 才以本人 NPC 出现，小禾在 M00 与可选林腹救援中出现。

## 完整结局与持久进度

M14 的主线节点依次辨认异常接头、恢复回流、守住稳定窗口、放慢光流，并与岑灯会面。暮根之心解除后，`outro` 提供完整结局：古树保留、灯塔修复、导师生还、两人返村、阿芙提供热水、小禾纠正路标、林恩把小灯留给后来的人。

主线机关、能力、收集与 Boss 完成均应永久保存。Boss 死亡、奖励授予与下一图解锁需统一幂等结算；已经完成的主线对象不在死亡或回访时要求重做。导师相关记录始终可重读，阿芙移动不丢失关键交易信息。任何护符、货币或支线完成度都不能代替必需能力，或阻止进入最后结局。

## 目前时长估计与差距

下面是基于内容的估计，**没有真人首次通关计时**。初稿只有约 6,475 字符与简单能力检查时，首玩主线约 30–60 分钟、全探索约 45–90 分钟是合理警示区间；它不支持原定五小时。扩写正文、近距显形、真实能力操作、三音问答、差异 Boss 与三十个可操作机关增加了有效内容，仍不能把数量换算成五小时达标。
