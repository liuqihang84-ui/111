# 森林正式环境素材

`forest_ancient_tree.png` 是可独立摆放的单棵暮色古树 PNG，作为原创新手森林的环境资产。它不是概念图背景，也不包含角色、地面、阴影、文字或 UI。旧32×48角色规范独立保留；当前林恩使用[独立重画的64×96像素图集](../art/characters/lynn_hd/README.md)。0.3.1-dev新增的地表与植被来自[原创绘图工具](../../tools/environment-art-provenance.md)，没有修改本页古树PNG。

## 图像与锚点

- 画布：1024×1536，RGBA PNG，透明背景；全轮廓均在画布内，四边存在透明边距。
- 非零 alpha 包围盒：左上 `(17,65)`，右下排他边界 `(1011,1489)`；肉眼可见主体的 alpha≥128 包围盒为 `(21,75)` 至 `(1008,1487)`。
- 建议树脚锚点：源画布 `(560,1380)`，归一化 `(0.546875,0.8984375)`。这是树干与根系的落地中心；前伸根尖的最低可见像素约 y=1488，不作为深度排序脚点。
- 建议初始世界可见高度：260–320 像素；实际镜头下按人物、碰撞与道路可读性调整。按非零 alpha 高度1424计算，对应源图缩放约0.183–0.225。

树冠以蓝绿、深青色叶群组织体积；褐色粗干与根系带少量暖色上左侧边光。采用斜45°正交游戏环境方向的手绘 HD-2D 造型，不使用其他游戏截图或贴图。
