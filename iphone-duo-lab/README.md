# Duo / Inside

Procedural Three.js iPhone Duo explorer, including folding, sequential disassembly, component details, and browser-local camera gestures.

Deploy this directory as a Render Static Site. Build command: `true`. Publish directory: `dist`. No install, server, secrets, or external assets are required.

Prepared from the existing V3 website source, commit b8bb8534270bde02eb479969dd1c029defc3a297. Three.js and OrbitControls retain their bundled MIT license in dist/vendor/THREE-LICENSE.txt.
