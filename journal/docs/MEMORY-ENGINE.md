# 立体记忆卡组

默认首页是 Three.js 0.180 WebGL 2 场景，包含独立的横向文字卡、照片卡和小事卡。它没有册子模型、纸张纹理、桌面道具或映射到 3D 页面上的输入框。编辑从真实卡片的 raycaster 点击打开旁侧原生输入栏。

每张卡有连续圆角的 ExtrudeGeometry 薄玉外壳，包含 3 段倒角、0.092 世界单位厚度；卡片正面是对齐 UV 的 ShapeGeometry，承载由当前记录生成的本地 CanvasTexture。正面保持真实文字和照片的可读颜色，独立的 MeshPhysicalMaterial 外壳通过本地 RoomEnvironment/PMREM、方向光和轻微半透产生反射及连续边缘。空记录只有一张文字提示卡，提示不写入存储。

真实非空任务才产生小事卡。每个有效本地照片对象产生独立照片卡，场景显示最新 6 张；全部照片仍保留在 model v1，由编辑栏访问。照片源接受 model 的嵌入式 PNG/JPEG/WebP 校验，不读取远程图片。旧贴纸对象不加入新卡组，旧构图编辑器继续保留它们。

展开和收拢改变实际卡片 Group 的位置、旋转及世界矩阵，默认前侧视角能看到独立卡片的厚度。卡面共享前侧法向、各卡仍有独立平面内角度；所有位置沿这个法向分层，每层间距为 0.17，大于 0.092 的真实卡片厚度。布局插值只改变平面内角度和位置，整个过程保持分层间距，避免卡面相互穿透。两种布局使用共同取景范围，变换期间与结束时保持一致的相机取景，不在动画末尾突然缩放。拖动调整真实透视相机，复位回默认位置。Pointer 移动超过 7 CSS px 后视为拖动，不触发卡片编辑。窄屏重排卡组并按 host 宽高自动调整相机距离，保留页面纵向滚动。

`setEntry()` 的异步字体、照片解码使用 revision 丢弃过期结果。替换卡片与 dispose 会释放对应纹理、几何体、材质和环境 render target。Reduced motion 直接应用布局和拖动目标。WebGL context lost 停止渲染并通过 onAvailability(false) 交给原生卡片回退，记录数据不依赖 GPU。

文字卡预览保留安全的左侧文字栏，标题纹理字号为 82、正文为 52，小事为 54；前侧照片可以与未放文字的右侧区域重叠。手机重排将文字卡上移、照片下移，并收紧取景留白，让标题、正文预览和小事更易识别。完整记录始终在原生编辑栏中读取和修改，预览缩略和省略号不会改写存储。

实际 canvas 的 `__memory3D.inspect()` 提供相机矩阵、卡片真实位置/旋转/世界矩阵、像素采样得到的纹理哈希、几何体顶点数、材质颜色、厚度、实际渲染帧数和绝对浏览器坐标的投影中心。各卡 `planeNormal`、`planeRange` 和 `measuredDepth` 来自正面与外壳全部实际顶点在世界空间的投影，可以直接核对相邻卡片之间的真实净距。`data-renderer="memory-webgl"`、`data-layout`、`data-settled` 和 `data-ready` 可用于等待实际绘制结果；这些数值来自当前场景。
