# 一日一笺 · 三维册页视觉规范

此版本将手账作为可操作的三维册子呈现。封面、书脊、装订厚度、翻动纸页和光影来自实时几何；页内文字和素材仍是可编辑的数据。册页的印刷秩序延续纸白、墨黑、朱线与矩形题签，界面、封面、月历和纸品共用同一套识别。

空间感需要在交互中成立：拖动能改变册子的角度，开合能露出页边和书脊，翻页能看到纸面弯曲，进入书写后可以直接编辑当前页。静态素材、纸纹照片和大面积投影不承担这些动作。

## 色彩

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 案面 | `#EDECE6` | 平整背景，不叠木纹、噪点或黄米渐变。 |
| 纸白 | `#FFFEF9` | 册页、封面、抽屉与对话框共用。 |
| 墨黑 | `#242624` | 字标、标题、主要内容、书脊与主要按钮。 |
| 辅文 | `#85877F` | 日期、工具说明、记录信息。 |
| 细线 | `#DCDDD5` | 纸面分隔、输入框、月份网格。 |
| 朱红 | `#BD3E32` | 书脊标记、当前栏目、记录标记、选中操作与印记。 |

朱红是唯一强调色。三种封面只有纸白、墨黑与朱红的面积关系变化，图形位置、字体和规则一致。

主要操作按钮使用墨黑底、纸白字；朱红用于身份标记与当前状态。避免把每一个工具都染成朱红而削弱印记的识别。

## 字标和共同图形

主要字标是宋体「一日一笺」，旁边的 `3 × 24 px` 朱红窄线来自书脊。该窄线在封面、日期、月历记录和导航中重复使用。字标不用通用羽毛图标替代。

图形只有四种基本元素：窄线、矩形题签、方形印记、水平分隔线。素材中出现的纸条、框签、编号和印记必须沿用这些元素。默认界面不放钢笔、胶带卷、夹子和仿古便笺。

## 字体和尺寸

| 层级 | 规格 |
| --- | --- |
| 桌面字标 | Guanwu Serif；22 px；字距 3 px。 |
| 页面标题 | Guanwu Serif；32 px；行高约 44 px；长标题在应用中按可用宽度缩小。 |
| 正文 | 系统无衬线；16 px；行高 30 px。 |
| 工具文字 | 系统无衬线；13 px；行高 20 px。 |
| 页内日期 | 11 px；辅文色；数字使用等宽数字。 |
| 输入字段 | 16 px；防止手机聚焦时产生浏览器自动放大。 |

主要操作按钮提供至少 `44 × 44 px` 的命中范围。册页缩小时，素材缩放手柄用页面缩放值的倒数计算尺寸，屏幕上的命中范围保持 44 px。纸页直接书写区会随整页缩放，手机可打开「编辑文字」使用完整字号字段。

## 布局、三维材质与书写

顶栏保留字标、三项导航与更多入口。桌面编辑区最大宽度为 1040 px，初始展示闭合册子，点击封面或「打开手账」进入展开状态；周围使用与界面一致的平整案面色。没有桌面摆件、额外卡片、营销标题和常驻素材栏。

浏览模式中的书封、页块、弯曲纸页和书脊通过 WebGL 实时绘制。封面为低光泽的朱红、墨黑或纸白，页边有真实厚度，接触阴影随书物姿态而改变。纸页正面平整，只有装订附近的微弯和受光差异，保留印刷内容的清晰度。避免闪亮塑料、夸张黄光、木纹桌面、皱褶贴图和持续自主摆动。三维地面与页面背景必须同色，不能出现像图片框的独立白矩形；照明校准要保留朱红封面与墨字的对比，题签必须正读。

桌面浏览舞台高度为 `clamp(520 px, 70dvh, 760 px)`。书写时，镜头移到右页正上方，保留册子的左页、书脊与页边；舞台高度为 `clamp(760 px, 86dvh, 920 px)`，允许自然滚动，以便文字获得更大的阅读尺寸。手机舞台随视口高度变化，目标页保持完整，编辑文字抽屉提供 16 px 的完整字号输入。

书写层使用原生输入框和可操作素材，叠加在真实三维右页的投影矩形上。位置与缩放来自三维相机的实际投影，不能通过固定边距猜测。书写时右页的三维纹理切换为空白纸，原生文字不会和纹理中的文字重叠。书写层的底色透明，取消额外的仿书脊、纸叠与纸面阴影，避免两套纸物同时出现。

当前页的日期、随笔、心情、待办、照片和纸品在浏览模式下成为实际册页内容，进入书写后继续编辑同一份记录。固定 `640 × 840` 的数据坐标保持不变，三维浏览角度不进入素材拖动与缩放计算。

浏览模式的开合、书写和恢复角度位于舞台下方的紧凑控制条；书写模式把「看整册」放在顶部编辑操作中，首屏即可返回浏览。交互入口使用 44 px 命中范围；当前模式以朱线表示，书写入口以墨黑按钮表示。只保留简短的旋转操作提示，不在纸面增加教程段落。减少动态效果的系统偏好应停用过渡运动，保留书物几何和所有功能。

素材抽屉默认关闭。桌面为右侧浮层，手机为底部浮层，并提供可见关闭入口。打开抽屉不改变书写坐标。选中素材的操作条固定在屏幕下方，不占页面流布局；拖动只增大接触阴影，不改变用于命中计算的物件几何。

不支持 WebGL 的设备继续使用普通册页编辑视图，可以书写、保存、导出和恢复记录，并明确显示渲染状态。降级视图保留纸色、字体和同一组朱线识别，不假称运行了三维场景。

## 封面、素材与旧记录

封面共用题签位置、书脊线、编号与字体。书架采用简洁的册子索引，主编辑区中的同一本书则可以实时旋转和开合。二者沿用同一封面身份，不加入桌面摆件。

封面标题按标题长度与实际封面宽度共同缩小，最多显示两行。很长的标题以省略号收尾，完整名称保存在数据中，并在封面下方显示，避免越过题签边框。手机的小字与题签间距另有缩放规则。

新的默认素材以印刷纸品为主：纸条、题签、索引签、双线框、朱印、日印、远山和植物拓印。旧版写实小物保留资产 ID 与读取兼容，收进「旧藏」，以免改版损坏已有手账。它们不作为新版本的默认开页装饰。

## 审核方式

同时检查三维浏览、旋转后角度、封面开合、纸页翻动、书写平面、书架、月历、工具和手机界面。去掉文案后，这些界面仍需由相同的朱线、题签、方印、字体与间距被识别为一套。

三维验收需要比较实际交互前后的视角、几何和光影，检查纸页纹理是否来自当前记录，以及书写坐标能否准确对齐真实右页。还要检查原生文字输入、素材拖动和 44 px 缩放手柄的准确性。不以单张截图、CSS 类名或测试数量判断空间感与美术质量。
