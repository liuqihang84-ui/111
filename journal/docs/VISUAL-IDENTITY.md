# 一日一笺 · 册页印刷视觉规范

此版本以私人册页的印刷秩序建立独立识别。页面、封面、月历、素材和工具使用同一组纸色、墨色、朱线与矩形题签。装订厚度服务于册页的空间感，装饰物不承担品牌识别。

## 色彩

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 案面 | `#EDECE6` | 平整背景，不叠木纹、噪点或黄米渐变。 |
| 纸白 | `#FFFEF9` | 册页、封面、抽屉与对话框共用。 |
| 墨黑 | `#242624` | 字标、标题、主要内容、书脊与主要按钮。 |
| 辅文 | `#85877F` | 日期、工具说明、记录信息。 |
| 细线 | `#DCDDD5` | 纸面分隔、输入框、月份网格。 |
| 朱红 | `#BD3E32` | 书脊标记、当前栏目、记录标记、选中操作与印记。 |

朱红是唯一强调色。三种封面只有纸白、墨黑与朱红的面积关系变化，图形位置、字体和规则一致。

主要操作按钮使用墨黑底、纸白字；朱红用于身份标记与当前状态。避免把每一个工具都染成朱红而削弱印记的识别。

## 字标和共同图形

主要字标是宋体「一日一笺」，旁边的 `3 × 24 px` 朱红窄线来自书脊。该窄线在封面、日期、月历记录和导航中重复使用。字标不用通用羽毛图标替代。

图形只有四种基本元素：窄线、矩形题签、方形印记、水平分隔线。素材中出现的纸条、框签、编号和印记必须沿用这些元素。默认界面不放钢笔、胶带卷、夹子和仿古便笺。

## 字体和尺寸

| 层级 | 规格 |
| --- | --- |
| 桌面字标 | Guanwu Serif；22 px；字距 3 px。 |
| 页面标题 | Guanwu Serif；32 px；行高约 44 px；长标题在应用中按可用宽度缩小。 |
| 正文 | 系统无衬线；16 px；行高 30 px。 |
| 工具文字 | 系统无衬线；13 px；行高 20 px。 |
| 页内日期 | 11 px；辅文色；数字使用等宽数字。 |
| 输入字段 | 16 px；防止手机聚焦时产生浏览器自动放大。 |

主要操作按钮提供至少 `44 × 44 px` 的命中范围。册页缩小时，素材缩放手柄用页面缩放值的倒数计算尺寸，屏幕上的命中范围保持 44 px。纸页直接书写区会随整页缩放，手机可打开「编辑文字」使用完整字号字段。

## 布局与材质

顶栏只有字标、三项导航与更多入口。编辑页以 `640 × 840` 册页为中心，取消营销标题、面包屑和常驻素材工作台。左侧 22 px 墨色书脊、右下三层纸边与接触阴影提供厚度。正文编辑平面始终正面，拖动坐标不因透视变化。

纸面平整，纤维、布纹和皱褶不作为全屏背景。纸白、规则的细线与排版间距是主要材质表达。物件只有轻微接触阴影；选中时显示朱色边界与局部操作。

素材抽屉默认关闭。桌面为右侧浮层，手机为底部浮层，并提供可见关闭入口。打开抽屉不改变纸页的尺寸和坐标。心情、照片和备份均在需要时调用，不给空白纸页增加提示区块。

选中素材的操作条固定在屏幕下方，不占页面流布局，首次选中和拖动起手都不改变册页位置。提示浮层位于操作条上方。

## 封面、素材与旧记录

封面共用题签位置、书脊线、编号与字体。书册旋转幅度小，厚度约 12 px，不加入桌面摆件。

封面标题按标题长度与实际封面宽度共同缩小，最多显示两行。很长的标题以省略号收尾，完整名称保存在数据中，并在封面下方显示，避免越过题签边框。手机的小字与题签间距另有缩放规则。

新的默认素材以印刷纸品为主：纸条、题签、索引签、双线框、朱印、日印、远山和植物拓印。旧版写实小物保留资产 ID 与读取兼容，收进「旧藏」，以免改版损坏已有手账。它们不作为新版本的默认开页装饰。

## 审核方式

同时检查编辑页、书架、月历、素材抽屉、更多菜单和手机界面。去掉文案后，这些界面仍需由相同的朱线、题签、方印、字体与间距被识别为一套。检查真实截图中的页面起始位置、留白、文字对比和选中对象，而不以 CSS 类名或测试数量判断美术质量。
