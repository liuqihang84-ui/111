# 一日一笺 · 温玉与苍墨视觉规范

v0.6 的工作区由一枚温玉色数字画布、一组日期索引和一枚编辑 dock 组成。版面用明确的大小差、色面比例和间距表达层次。记录仍可直接输入、编排和回顾；「空间预览」查看同一份内容的轻弧面与素材高差。

设计借用中国器物的含蓄轮廓、玉色的温润与章法里的虚实关系，转译为当代数字界面。大日期、柔角画布和苍墨主按钮共同形成可识别的整体。页内不再印刷合集名、分隔横线、题注或出版式页脚，信息移到画布外的交互层。

## 色彩

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 界面背景 | `#E8EBE4` | 平整、略深的玉灰空间，与实时三维背景一致。 |
| 温玉 | `#FCFBF6` | 主画布、工具面和对话框。 |
| 苍墨 | `#183B35` | 品牌、日期、内容、主要操作和选中日历格。 |
| 青釉 | `#536F63` | 次要图形、控制边界、选中框和素材主色；在背景上的对比约 4.56。 |
| 面内辅文 | `#61716A` | 温玉面内说明；在温玉上的对比约 4.97。 |
| 背景辅文 | `#5B6C63` | 导航、日期上下文与保存状态；在背景上的对比约 4.62。 |
| 细线 | `#D2DBD1` | 输入框和局部分隔，不作为全屏框架。 |
| 浅玉 | `#D9E1D5` | 素材与轻层次的辅助色面。 |
| 陶朱 | `#BC745E` | 素材中的小面积暖色，全界面视觉面积控制在约 2% 以内。 |

温玉与背景之间有可见但克制的明度差。苍墨集中在字标、大日期与主要操作，形成三处重心。界面文字不使用低对比的浅灰；素材的柔和颜色与操作的清晰程度分别处理。

## 字标与图形

品牌保留「一日一笺」，宋体字标旁是一枚分开的柔角 L 线与四分之一圆弧。线宽保持约 1.65 px，两部分不相接。品牌图形及素材轮廓共享短线、弧线、柔角和有间隔的组合关系，避免让每个图标都重复同一纹样。

图形的精细度由轮廓、间隔、边缘高差与色面比例承担。工作区不增加噪点、书脊、装订、仿宣纸纤维或桌面道具。原有素材继续可用，新默认素材服务于画布构图而非堆叠装饰。

## 字体与尺寸

| 层级 | 规格 |
| --- | --- |
| 桌面字标 | Guanwu Serif；23 px；字距 1.5 px。 |
| 桌面日期数 | Guanwu Serif；110 px；行高 1.12；等宽数字。 |
| 桌面月份 | 系统无衬线；14 px；行高 24 px。 |
| 手机日期数 | Guanwu Serif；39–52 px，月份和星期放在旁侧。 |
| 画布内容标题 | Guanwu Serif；32 px；行高约 45 px；长标题按宽度缩小。 |
| 画布正文 | 系统无衬线；16 px；行高 30 px；保留既有数据坐标。 |
| 主要导航与工具 | 系统无衬线；12–14 px；行高 20 px。 |
| 工具输入 | 系统无衬线；16 px；手机不使用缩小的输入字号。 |

宋体负责品牌、日期和内容标题，其余操作使用系统无衬线。所有主要控制保持至少 `44 × 44 px` 的命中范围；素材的缩放手柄按页面显示比例反向计算尺寸，屏幕上仍为 44 px。移动端另有「编辑文字」入口，使用原生大字号字段修改同一份内容。

## 版面和交互

顶栏以品牌与导航的疏密区分层次，不加贯穿全宽的分隔线。当前导航用短线标记。桌面编辑工作区使用 `176 px + 可伸缩画布` 双列，列间距 42 px，最大宽度 1120 px。左侧依次呈现合集名、月份、大日期、年份星期、切换提示和前后日期按钮；日期本身是可操作的输入入口。

右侧是主画布。实时三维舞台采用 `clamp(630 px, 76dvh, 780 px)` 高度；原生编辑层由引擎的真实投影矩形定位。22 px 的逻辑圆角用于画布外轮廓，内部保持 640 × 840 的数据坐标；标题顶边为 72 px，正文顶边为 148 px，待办沿用 380 px 起点。样式不得再平移、旋转或缩放投影编辑层，避免改变素材和触摸控制的位置。

编辑 dock 位于画布下方，容纳空间预览、历史、文字和加内容。它只有一个淡色实体面和一个苍墨主要按钮；预览状态在同一位置显示继续书写与重置视角。保存状态位于工作区末端，不写进画布。素材选中时的操作条固定在屏幕底部，不挤压页面。

760 px 以下变为单列。日期数与月份、星期横向组合在画布上方；合集名只占剩余空间，过长时省略。手机的书写舞台采用 `clamp(392 px, 112vw, 560 px)`，dock 保留 44 px 控制，320 px 屏幕不通过隐藏主要功能来腾出宽度。

默认页不填入示例内容、照片、素材或假记录。打开即可输入；空间预览读取真实内容，回到书写时继续原有编辑。浅曲面与素材微小高差说明数字空间，切换日期采用必要的短过渡。减少动态效果的系统偏好保留输入和控制，停用多余过渡。

## 组件与素材

按钮和 dock 用圆角胶囊，画布、抽屉、收藏面和日历使用 18–24 px 柔角。工具面为温玉实体底，局部细线与柔和阴影说明层级；不使用层叠透明玻璃。工具页签是一枚内嵌的选择槽，主要素材格以同色底承托三维轮廓，不为每件素材增加高对比边框。

照片以柔角图像片呈现，没有白框、日期题注或拍立得外观。照片父元素不裁掉缩放手柄，实际图像自己使用圆角；整页继续裁切，保持素材留在数据坐标范围内。

收藏页面沿用温玉、浅玉与苍墨，主题面显示一个有辨识度的轮廓和编号；深苍墨主题的编号使用浅玉色保持可读性。合集名仅在面下显示一次，完整长名称自然换行。没有实体书的书脊、页块或厚封面。日历采用相同的温玉面，选中日为苍墨实心格，有记录的日期使用小圆点。320 px 屏幕上的月历面使用屏幕满宽和小内边距，让七列日期格仍各有 44 px 的触摸宽度。

新的默认八件温玉构件为玉题签、玉界框、清流线、薄玉弧、玉索引、轻折片、玉叠片与玉朱点。托盘以两列展示轮廓和倒角，旧藏保持更紧凑的三列。

原有资产 ID、主题 ID、JSON 备份、本地存储和数据坐标保持兼容。此前图形仍在对应旧藏分组，已有页面继续读取原素材。视觉更新不重写照片或用户文本。

## 视觉与几何验收

用真实浏览器分别查看 1440 px、390 px、320 px 的默认记录、实际编排、空间预览、收藏、日历、素材抽屉和对话框。比较日期、主画布和操作的面积关系，检查苍墨是否形成稳定重心，观察图形边缘和组件圆角是否统一。手机必须没有横向溢出，主要触摸入口仍为 44 px。

视觉检查与功能测试分别进行。视觉判断以真实运行页面为准，不用宣传效果图或测试数量替代。功能检查继续核对原生输入、素材移动、边缘缩放、历史、照片导出与备份恢复；空间检查核对真实相机、曲面几何、纹理和返回书写后的投影矩形。
