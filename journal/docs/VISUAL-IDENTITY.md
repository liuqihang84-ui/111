# 一日一笺 · 浮笺视觉规范

「浮笺」是一套数字手账界面：记录是可直接输入、编排和回顾的独立页面。空间感来自一枚轻薄画布的姿态、错层边和素材之间的微小高差。默认进入书写平面，选择「空间预览」时才查看页面的角度和层次。

青釉、玉白与陶朱来自中国器物色彩的抽象关系；留白、疏密与一弧一断来自器物轮廓和章法的提炼。界面保持当代编辑工具的清晰秩序，不增加桌面背景、装订细节、古装小物或拟真纸纹。

## 色彩

| 用途 | 色值 | 使用规则 |
| --- | --- | --- |
| 界面背景 | `#F1F3EF` | 同色平整空间，与实时三维背景一致。 |
| 玉白 | `#FFFDF8` | 主画布、输入面、工具抽屉与对话框。 |
| 深苔墨 | `#283F3C` | 字标、标题、正文与主要按钮。 |
| 辅文 | `#617369` | 日期、页面元信息、工具说明；在界面背景上对比约 4.52，在玉白上约 4.96。 |
| 细线 | `#DBE3DB` | 页内分隔、输入框与轻量边界。 |
| 青釉 | `#608678` | 品牌图形、选中框、当前状态与素材主色。 |
| 浅釉 | `#DCE8E0` | 当前日期底色、素材中的大块浅色与轻薄错层边。 |
| 陶朱 | `#C87560` | 素材和合集主题中的少量暖色。 |

文字以深苔墨和辅文色保证阅读。青釉与陶朱主要承担识别与美术构成，避免将正文和整排工具都染成强调色。材料均为低反差、不带噪点的纯色面。

## 字标与共同图形

品牌名称保留「一日一笺」。宋体字标旁是一枚「一弧一断」：柔角 L 线与四分之一圆弧，二者保持间隔。图形只在品牌、合集主题封面和素材中的索引符号三处使用。导航、日期与保存状态用简单圆点，不机械重复品牌纹样。

共同视觉语法是留白、柔角平面、短线与不闭合轮廓。无需模拟纸材磨损、印章渗墨、绳线或金属件来显示精致度。素材必须通过准确的轮廓、色面比例与同一组颜色被识别为一套。

## 字体和尺寸

| 层级 | 规格 |
| --- | --- |
| 桌面字标 | Guanwu Serif；22 px；字距 1.7 px。 |
| 当前日期标题 | Guanwu Serif；34 px；行高约 48 px；手机 25–27 px。 |
| 画布标题 | Guanwu Serif；32 px；行高约 45 px；长标题沿用按宽度缩小的规则。 |
| 正文 | 系统无衬线；16 px；行高 30 px。 |
| 导航与工具 | 系统无衬线；12–13 px；行高 20 px。 |
| 页内元信息 | 10–11 px；辅文色；数字使用等宽数字。 |
| 抽屉输入字段 | 16 px；手机保持可直接输入的字号。 |

宋体只承担字标、日期标题与内容标题，正文和操作标签使用系统无衬线。工具按钮、导航、更多入口和素材操作保持至少 `44 × 44 px` 的命中范围。画布缩小时，素材缩放手柄以缩放值的倒数计算命中尺寸，屏幕上仍为 44 px。

## 首屏与工作区

顶栏只有品牌、记录 / 收藏 / 日历与更多入口。记录页的简短标题区显示当前合集、今天或所选中文日期及星期，不出现宣传口号、英文装饰标签或重复的记录卡片。

日期导航与编辑操作位于主画布上方。默认可直接写字；「空间预览」进入三维查看，撤销、重做、编辑文字和加内容保留清晰入口。画布里的顶边只显示合集名与「一页私记」；页底只显示品牌「一日一笺」与字数。完整日期不在纸面重复印刷。

桌面工作区最大宽度 980 px，工具条最大宽度 920 px。日期标题与合集、星期信息横向排成一组，减少画布前的空白。三维书写舞台高为 `clamp(640 px, 74dvh, 780 px)`；手机的编辑与空间预览都使用 `clamp(380 px, 115vw, 475 px)`，让单页尽量占据可用宽度。

桌面和手机的页面数据坐标仍为 `640 × 840`。三维引擎给出书写平面的实际投影矩形，原生输入框和素材编辑层精确叠加在该矩形上。界面样式不得通过额外旋转、缩放或平移改变投影层的命中几何。

书写状态下三维底面显示空白页，页面数据由原生编辑层显示；空间预览使用当前记录的真实纹理，并把素材作为独立薄片放在画布上。两种状态读取同一份记录，不创建额外页面，也不把视角写入编辑历史。

## 空间、组件与交互

主画布是轻薄的数字片层。低反差错层边和柔和接触阴影说明位置，空间预览的转动说明高差。页面周围不显示实体书的对页、厚封皮、页块、书脊、缝线或桌面道具。默认界面保持稳定，只有用户请求空间预览或切换日期时才发生必要过渡。

按钮采用 10 px 柔角；抽屉、对话框采用 14–16 px 柔角。所有工具共用玉白实体底面、细线和浅阴影，不叠加多层玻璃效果。素材抽屉默认关闭，桌面在右侧，手机在底部；打开抽屉不改变画布坐标。

选中素材的操作条固定在屏幕底部，不挤压画布。拖动只增加轻微阴影，不额外改变物件的坐标平面。减少动态效果的系统偏好停用过渡，保留全部输入与操作。

收藏采用数字索引面板。主题名为「青釉 / 陶朱 / 玉白」，三个面板共享图形母题与浅色面，面上只有抽象图形与编号；只用一层 5 px 的错层边说明合集关系。合集名字仅在面板下方显示一次，长名称自然换行并保留完整内容。打开合集是短距离片层过渡，没有翻硬皮封面的动作。

日历沿用玉白面、青釉选中态与圆点记录标记。日期是独立可点击格，采用轻底色和边界，无沉重表格线或纸叠投影。

## 素材与兼容

新的默认八件素材为弧光、小折、云阶、留白框、波纹、月牙、微光、书签，遵循相同的低浮雕色面、柔角、弧线与短线语言。此前的印刷纸品和写实素材放在「旧藏」。美术细节集中在用户选择的素材上，默认空白页不填充示例文字、照片、贴纸或假记录。

旧资产 ID、封面 ID、备份结构、数据坐标和本地存储兼容保留。旧版素材放在「旧藏」，用户已有编排继续读取。视觉主题变更不重写照片或改动用户内容。

不支持 WebGL 的设备使用同一套颜色和字体的普通可编辑画布，仍可输入、保存、导出和恢复。状态信息应说明实际渲染情况。

## 审核方式

检查空白记录页、实际编排、空间预览、收藏、日历、抽屉与对话框能否由相同色彩、字标、轮廓和间距被识别为一套。分别查看 1440 px、390 px、320 px 的真实浏览器截图，确认手机没有横向溢出、触控入口仍为 44 px、首屏画布能够直接编辑。

空间验收比较实际交互前后的相机与薄片几何，确认显示内容来自当前记录；编辑验收核对输入、素材拖动、边缘缩放和导出。视觉评审同时查看默认空白页和用户实际添加内容的页，不以静态效果图或测试数量代替美术判断。

选中小素材时，44 px 缩放触摸目标位于可用外角；页面边缘按旋转后的局部重叠面积选择空余角，避免盖住素材中心的移动区域。未选中时不显示此控件。
