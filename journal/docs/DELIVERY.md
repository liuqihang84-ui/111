# 一日一笺 0.4.0 交付说明

本版提供可直接操作的实时3D手账：默认合册，点击封面展开，拖动改变相机视角，前后一天卷页切换。封皮、书脊、纸层、纸页沟槽和缝线由本地Three.js程序建模，印刷内容随当前记录更新；照片与纸品为独立有正反面和边缘的薄纸网格。

## 操作

点右页或「写一笔」进入同一真实纸面的原生书写，右页展平、镜头归正，方便中文输入和精确拖动。「看整册」位于顶部操作行。加内容、编辑文字和素材操作按需出现；镜头和浏览模式不进入记录与撤销历史。

纸白、墨黑、朱红的统一UI / VI延续。八件印刷纸品、三种封面、旧十二件小物和已有素材ID保留；已有浏览器记录及历史JSON兼容。每个完整素材手势占一次撤销，44px实际触摸柄保留。

更多操作导出1280×1680平面纸页PNG与全部手账JSON；导入前先下载当前备份，无效备份不替换记录。记录和照片留在当前浏览器，跨设备或地址前使用JSON迁移。

## 运行与边界

`bash tools/install.sh` 安装、测试与构建；`PORT=4180 bash tools/serve.sh preview` 生产预览，`dev` 开发。3D需要WebGL 2；不可用时保留普通书写、保存和导出。减少动态偏好会立即完成过渡。启动细节见 [START.md](START.md)。

当前托管浏览器限制file://，保留策略并使用允许的真实HTTP断网验收，本地双击未在此环境实测。内容保存于当前浏览器，不含账号、云端同步或公开站点部署。每页标题24字、随笔260字、待办5件、素材30件，最多20本；照片最大15MB、最长边缩至1600px；PNG过多换行可能缩小或截短，JSON保留原文。
