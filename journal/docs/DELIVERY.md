# 一日一笺 0.3.0 交付说明

本版将手账收成一套「册页印刷」UI / VI：纸白、墨黑、朱红，宋体字标、窄线、矩形题签与编号贯穿封面、纸页、月历和工具。默认直接写一本「日常」的空白页；未书写的日期不计作记录。移除木纹桌面、皱纸背景、摆件、宣传说明与常驻素材栏，保留窄脊、薄纸边和轻投影。

## 操作与数据

「写 / 册 / 历」切换工作区；「加内容」打开八件新印刷纸品与照片，「编辑文字」提供手机大字号输入、心情和小事。选中素材后才出现复制、置前、设置与删除；浮动条不推动纸页。缩放控件可见图形16px，实际触摸区44px。移动/缩放/旋转、整次手势撤销重做、历史备份与旧素材 ID 保留。

三种封面为原创 SVG，朱页、墨页、素页共用题签位置与规则。旧十二件 PNG 小物收在「旧藏」。新 PNG 图集的提示词、坐标与透明审图见 [PRINT-ART.md](PRINT-ART.md)，统一识别规范见 [VISUAL-IDENTITY.md](VISUAL-IDENTITY.md)。

「更多操作」提供1280×1680纸页 PNG、全部手账 JSON 备份/恢复与封面设置。记录保存在当前浏览器；照片仅在浏览器内处理。恢复前先下载当前备份，无效备份保留原状态。已有记录不重置。

## 文件与边界

网页ZIP含单文件HTML、中文README和完整许可证；源码ZIP含应用、原始美术、视觉规范、锁文件、测试与启动脚本，不需要相邻美术工作台。使用前完整解压。

托管浏览器限制file://，本轮真实HTTP载入后断网测试，未绕过策略；用户本地文件打开方式未在本环境实测。内容属于当前浏览器存储，更换设备、浏览器、地址、路径或清理数据前需JSON备份。没有账号或云端同步，未部署公开站点。

每页标题24字、随笔260字、待办5件、素材30件，最多20本手账。PNG按纸面空间排版，过多换行可能缩小或截短，JSON保留文字。照片最多15MB、最长边缩至1600px，纸面照片按相框比例裁切。
