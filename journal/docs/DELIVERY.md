# 一日一笺 0.2.0 交付说明

本版将手账呈现为一张实体桌面：布面书册有封皮、书脊和纸边，打开后可见内封便签、装订光影与纸页叠层。草木与文具使用 12 枚透明 PNG 材质小物，纸底使用新的纤维纸纹 PNG。同一张新布面山水 PNG 通过三种配色提供封面选择。

## 已完成的使用流程

初次进入书桌可挑选示例手账，也可创建新册或修改名称与封面。点开书册会掀开封面，前后日导航以翻页动画切换日期；月历可回看已有记录。书册深度与动画使用 CSS 3D 变换和阴影，编辑纸面只作平面缩放。

每页可编辑标题、随笔、心情和五件以内的待办；上传照片；添加、拖动、用圆角手柄缩放、旋转、摆正与删除贴纸或照片。浮动工具提供撤销、重做、复制与置于最前。白花枝使用旧资源 ID `icon-orchid`，以保留既有手账和备份兼容。

手机使用紧凑导航和可展开的素材托盘，标题与随笔另有 16px 输入区。触摸拖动与手柄缩放按照实际纸面比例换算坐标，旋转后的素材边界也限制在纸面内。图片在当前浏览器内处理，不发送服务器。

内容自动保存，可下载完整纸页 PNG 展示图片，或下载全部手账的 JSON 备份。恢复 JSON 前先下载当前备份；无效备份保留原状态。

## 文件与使用边界

网页 ZIP 内含 `yiri-journal.html`、中文 README 和完整许可证。解压后可用现代浏览器打开。当前环境的 Chromium 管理策略限制 `file://`；本轮使用真实 HTTP 载入后断网验收；本地文件源打开方式未在本环境实测，未修改或绕过管理策略。

内容保存在当前浏览器的本地存储，容量由浏览器决定。空间不足或存储不可用时页面显示提示，当前内存中的内容仍可导出。换设备、地址、浏览器或文件路径前应导出 JSON 备份；PNG 用于展示，JSON 用于恢复编辑。

每页标题最多 24 字、随笔 260 字、五件待办、三十件素材；最多二十本手账。PNG 为 1280 × 1680。标题和随笔在导出时按纸页空间调整字号；超过空间的过多换行会截短并出现省略号，JSON 保留完整文字。上传照片最多 15 MB，浏览器内缩小至最长边不超过 1600px；纸页照片按边框比例裁切显示。

本版提供网页使用与独立源码，没有账号、云端同步或在线生成模型。主视觉素材已经生成并随包内嵌，使用时无需 API 密钥。旧 SVG 仅保留兼容。没有部署公开站点或启用 GitHub Pages；原美术工作台与旧 Godot 游戏保留原目录和已有成果。

## 开发与环境

执行 `bash tools/install.sh` 安装、测试与构建；`PORT=4180 bash tools/serve.sh preview` 启动生产预览，开发用 `dev`。构建将同一份单文件保留到 `dist/yiri-journal.html`，便于重现离线浏览器验收。独立源码 ZIP 解压后的 `journal/` 无需相邻美术工作台即可安装。

环境安装与启动配置草稿保留此前美术工作台与旧游戏说明。每个任务已有隔离云环境，使用现有检出，不额外创建 Git worktree。保存配置不等于发布云环境快照，也未证明下一任务恢复已经验证；新任务需要重启现场服务。具体指令见 [START.md](START.md)。
