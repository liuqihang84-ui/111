# 一日一笺 0.7.0

默认记录方式改为真实三维记忆卡片。文字、照片和小事分开呈现，「收拢 / 展开」改变卡片的位置、旋转与遮挡，点击卡片按需打开原生编辑面板。首次无数据只有空态入口，不生成示例日记、照片或待办；本版没有新增 AI 图片作为默认视觉。

## 使用与数据兼容

「记一笔」编辑当天同一份标题与随笔；「添照片」上传本地图片；「加小事」新增、完成和删除待办。场景最多展示最新 6 张照片，面板与 JSON 保留全部媒体。日期、收藏、日历、撤销、重做及自动保存继续可用。

「旧画布」保留原来的长页原生编辑、全部拼贴对象、36 件历史素材和空间预览。卡组不重写原对象的坐标、尺寸和旋转；已有本地存储、资产 ID、手账 ID 与版本 1 JSON 格式继续兼容。

记忆卡片 PNG 为 `1440 × 1024`，呈现文字、最多 6 张最新照片和小事；旧画布 PNG 为 `1280 × 1680`，保留全部原坐标拼贴。JSON 用于恢复全部手账；导入验证格式，覆盖前先下载当前备份，无效文件不替换记录。

## 启动与边界

`bash tools/install.sh` 安装、测试并构建；`PORT=4180 bash tools/serve.sh preview` 启动生产预览，`dev` 为开发。记忆卡片需要 WebGL 2；不可用时普通内容列表继续编辑、保存、导出，旧画布保留普通书写。详见 [START.md](START.md)。

托管浏览器限制 `file://`，保留策略，通过真实 HTTP 断网验收；本地双击未在此环境实测。没有账号、云同步或公开网站。每个日期标题 24 字、随笔 260 字、小事 5 条、对象 30 件，最多 20 份手账；照片最大 15 MB、最长边缩至 1600px。分享图的文字按画幅截取，JSON 保留原文和全部媒体。迁移设备、浏览器、地址或文件路径前导出 JSON。

可复用启动配置与上述流程一致，保留美术工作台及旧 Godot 项目。云环境草稿保存不执行命令或发布快照；跨任务保留需在环境设置中保存并发布，未来任务恢复未独立验证。已有 `journal-playtest` 分支的源码、下载和实录上传后另行核对远端字节。
