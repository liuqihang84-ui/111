# 一日一笺 0.5.0 · 浮笺

本版以数字记录为中心：打开直接编辑单张画布，浅釉错层和轻弧面提供克制的空间感。独立视觉采用玉白、青釉、墨色与少量陶朱，「一弧一断」贯穿品牌和合集图形；八件抽象光片使用同系列倒角与柔光。收藏为数字面板，照片为无框柔角图像片。

## 使用

「记录 / 收藏 / 日历」切换编辑、合集和回看。「加内容」按需打开八件光片与照片；「编辑文字」提供大字号输入、心情和小事。「空间预览」查看同页真实3D，点击画布或「继续书写」返回原生编辑。日期切换约620ms浅弧流转，结束保持书写；减少动态偏好使用直接切换。

原8件印刷素材在「印刷旧藏」，原12件小物在「旧藏」。已有记录、资产ID、收藏ID、本地存储与JSON结构兼容保留。实际拖动与缩放各占一次撤销，44px触摸控件保留。

「更多操作」导出1280×1680 PNG与全部手账JSON；恢复前下载当前备份，无效备份不覆盖记录。内容与照片存于当前浏览器，迁移设备、浏览器、地址或文件路径前导出JSON。

## 启动和边界

`bash tools/install.sh` 安装、测试并构建；`PORT=4180 bash tools/serve.sh preview` 启动生产预览，`dev` 为开发。空间预览需要 WebGL 2，不可用时继续编辑、保存与导出。详见 [START.md](START.md)。

托管浏览器限制file://，保留策略并通过真实HTTP断网验收；本地双击未在此环境实测。没有账号、云同步或公开网站。每页标题24字、随笔260字、待办5件、素材30件，最多20份手账；照片最大15MB、最长边缩至1600px；PNG在过多换行时可能缩小或截短，JSON保留原文。
