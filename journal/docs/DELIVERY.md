# 一日一笺 0.1.0 交付说明

这是使用中国古代册页美学与观物原创素材制作的电子手账原型。研究成果已转为实际界面和操作：三种封面、十二枚草木与日常贴纸、纸纹、山水留影，配合书架、日期纸页和月历。

## 已完成的使用流程

创建或修改手账与封面；选择日期；编辑标题、随笔、心情和五件以内的待办；上传照片；添加、拖动、缩放、旋转和删除贴纸或照片；自动保存；下载 PNG 展示图片；下载或恢复完整 JSON 备份。恢复前先下载当前备份，无效备份保留原状态。

手机有大字号标题与随笔编辑区，避免只在缩小的纸面上输入。触摸拖动按照纸页缩放换算坐标，旋转后的素材边界也限制在纸面内。所有图片在当前浏览器内处理，不发送服务器。

## 实际验证

- 锁定安装：`npm ci` 安装 109 个包成功。
- 单元测试：19/19 通过，涵盖日历日期、数据与备份校验、损坏存储、图片格式及旋转边界。
- TypeScript 与生产构建：通过；单文件资源校验、ZIP 成员/CRC/实际字节检查通过。
- 浏览器测试：10/10 通过，2026-10-04 12:50 北京时间开始，耗时 17.9 秒，失败/跳过/不稳定均为零，没有控制台错误或未捕获异常。结果由 `test-results/browser-report.json` 生成，详见 QA.md。
- 离线：真实 HTTP 载入的 HTML 与发布文件逐字节一致，不加载其他 HTTP 资源；随后断网，文字编辑、SVG 像素变化和含照片的 PNG 导出均通过，断网后 HTTP 请求为零。
- 桌面 1440px 与手机 390px 的编辑器、书架和月历已检查，无横向溢出；手机还验证了实际触摸操作和不小于 16px 的文字编辑输入。

## 文件与使用边界

网页 ZIP 内含 `yiri-journal.html`、中文 README 和完整许可证。解压后可用现代浏览器打开；环境中的 Chromium 管理策略禁止 `file://`，因此本环境没有实测双击本地 HTML 的文件源行为，未修改或绕过策略。

内容保存在当前浏览器的本地存储，容量由浏览器决定。空间不足或存储不可用时页面显示提示，当前内存中的内容仍可导出。换设备、地址、浏览器或文件路径前应导出 JSON 备份；PNG 只作展示，不能恢复编辑。

每页标题最多 24 字、随笔 260 字、五件待办、三十件素材；最多二十本手账。PNG 为 1280 × 1680。随笔在导出时按纸页空间缩小排版，超过空间的过多换行会截短并出现省略号，JSON 保留完整文字。上传照片最多 15 MB，浏览器内缩小至最长边不超过 1600px；纸页照片按边框比例裁切显示。

本版提供网页使用与独立源码，没有账号、云端同步或在线生成模型。没有部署公开站点或启用 GitHub Pages。原美术工作台与旧 Godot 游戏保持原目录和分支。

## 开发与环境

执行 `bash tools/install.sh` 安装、测试与构建；`PORT=4180 bash tools/serve.sh preview` 启动生产预览，开发用 `dev`。构建会将同一份单文件保留到 `dist/yiri-journal.html`，便于重现离线浏览器验收。独立源码 ZIP 解压后的 `journal/` 无需相邻美术工作台即可安装。

已保存电子手账的环境安装与启动配置草稿，保留之前美术工作台和旧游戏说明。保存配置不等于发布云环境快照，也未验证下一任务恢复；现场服务在新任务需要重启。
