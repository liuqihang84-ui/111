# 一日一笺 0.6.0 · 浮笺

本版以「温玉 × 苍墨」重整电子手账：日期导航独立、单张圆角数字画布与短操作区形成清晰主次。薄玉素材提供题签、框界、线条与层次，界面采用暖白、苍墨、玉青及少量陶朱。默认直接原生书写，可选空间预览查看同页的真实薄片与轻弧面。

## 使用

「记录 / 收藏 / 日历」切换编辑、合集与回看。日期锚点和前后日按钮用于切换日期。「加内容」按需打开八件薄玉素材与照片；「编辑文字」提供大字号输入、心情与小事。「空间预览」查看真实 3D，点击画布或「继续书写」返回原生编辑。减少动态效果偏好保留功能、减少过渡运动。

原八件光片收于「浮笺旧藏」，八件印刷图形在「印刷旧藏」，十二件材质小物在「旧藏」。已保存记录、资产 ID、收藏 ID、本地存储与 JSON 结构兼容保留。拖动与缩放各占一次撤销，44px 触摸控件保留。

「更多操作」导出 1280 × 1680 PNG 与全部手账 JSON；恢复前下载当前备份，无效备份不覆盖记录。内容与照片存于当前浏览器，迁移设备、浏览器、地址或文件路径前导出 JSON。

## 启动与边界

`bash tools/install.sh` 安装、测试并构建；`PORT=4180 bash tools/serve.sh preview` 启动生产预览，`dev` 为开发。空间预览需要 WebGL 2；不可用时继续编辑、保存与导出。详见 [START.md](START.md)。

托管浏览器限制 `file://`，保留策略并通过真实 HTTP 断网验收；本地双击未在此环境实测。没有账号、云同步或公开网站。每页标题 24 字、随笔 260 字、待办 5 件、素材 30 件，最多 20 份手账；照片最大 15 MB、最长边缩至 1600px；PNG 在过多换行时可能缩小或截短，JSON 保留原文。

可复用启动配置与上述流程一致，保留美术工作台及旧 Godot 项目。云环境设置草稿的保存不执行命令或发布快照；后续环境需在设置中保存并发布，未来任务恢复未独立验证。源码、下载与实录针对已有 `journal-playtest` 分支交付，上传后的远端字节验证另行记录。
