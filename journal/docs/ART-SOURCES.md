# 美术与字体来源

本项目的美术素材来自同一工作区的 `art-workbench` 本地素材库，图形源码见 [materials.ts](../../art-workbench/src/data/materials.ts)。这些素材以传统形式为灵感，重新设计为现代简化矢量图；没有使用历史扫描图或馆藏复制图。

原样提取的 SVG 包括：

- 贴纸：`icon-orchid`、`icon-plum`、`icon-bamboo`、`icon-fan`、`icon-moon`、`icon-seal`、`icon-teacup`、`icon-book`、`icon-lotus`、`icon-ginkgo`、`icon-umbrella`、`icon-swallow`。
- 装饰：`frame-key-corners`、`texture-paper-fibers`、`pattern-bluewhite-vine`。
- 场景：`scene-southern-river`、`scene-bluegreen-ridges`、`scene-literati-bank`。

`cover-mountain.svg`、`cover-orchid.svg`、`cover-indigo.svg` 和 `demo-landscape.svg` 是从本地原创简化矢量母题重新组合、布局和改色的新作品。视觉灵感包括吴门册页的疏朗花草、南宋小景的江岸留白、青绿山水的叠嶂、青花的蓝白纹样及蓝染的靛蓝色调。这些是宽泛的形式与配色参考，不对应某件古画、器物或工艺实物的复刻。

素材与字体均随项目本地交付，页面显示不依赖在线图片或字体服务。

字体从 `art-workbench/src/assets` 复制为 `src/assets/guanwu-serif.woff2`。原项目记录的 `Guanwu Serif` 为 Noto Serif SC 的衍生子集；字体采用 SIL Open Font License 1.1，随字体保留的原始版权声明与许可证全文见 [FONT-LICENSE.txt](../src/assets/FONT-LICENSE.txt)。
