# 浮笺空间画布

版本：0.5.0。核心实现为 `src/lib/book-scene.ts`，使用锁定的 Three.js 0.180.0。新版只呈现一个书写画布，空间感来自轻盈的浅釉错层、微弧曲面和短促流转。没有硬封皮、装订轴、左侧空页、布纹、纤维或旧纸效果。

## 画布与编辑

画布的设计坐标仍为 640 × 840，世界尺寸为 3 × 3.9375。主面使用 24 × 28 的网格；空间预览中的弧度不足世界单位 0.02，进入书写立即回到精确平面。两张独立浅色底板厚度为 0.012 和 0.014，提供低对比的错层边缘。场景底色为 `#F1F3EF`，书写面为 `#FFFDF8`，底板为浅釉 `#DCE8E0`。阴影来自方向光和真实模型，阴影图为 512 × 512。接收面靠近浮片下方，外投影透明度为 0.07；底板只超出画布 0.018 世界单位，两次偏移均低于 0.013，避免厚框板效果。

数字画面的颜色应忠实于设计。主面和照片、贴片使用带纹理的标准材质，较大的自发光分量保留原图颜色，较小的受光分量呈现曲面、遮挡和柔和阴影；没有用浓重摄影阴影模拟精致。照片及贴片是独立的 6 × 6 网格，按原始页面坐标定位，曲面轻微抬起并投射阴影。贴片图片仍是平面图形，未被声称为独立的立体雕塑。

默认直接进入书写，无需先打开封皮。`getWritingRect()` 用真实相机矩阵投影书写面四角，返回相对 Canvas 的 CSS 像素范围。原生 DOM 输入和可拖动素材覆盖同一投影范围，页面缩放直接取真实投影宽度 / 640；仅无 WebGL 的备用编辑路径测量 DOM 视口，不再让写态缩放依赖模式切换时会替换的 DOM 视口节点。场景中的对应文字和对象隐藏，避免双重显示。空间预览恢复当前记录纹理和独立对象，点击主面返回书写。镜头、预览和流转均不写入撤销历史。

## 日期流转

切换日期使用 620 ms 的短流转：单面轻微平移和倾斜，局部弧面顶点发生真实变化，并在中段淡出后切换下一日纹理再淡入。画布不绕装订轴翻转，也不会凭空出现第二个空页。流转期间投影书写层暂时隐藏，结束后恢复当前模式和真实投影范围。书写与空间预览之间的镜头归位为 360 ms。动画按实际经过时间计算，低帧率不会延长持续时间。

系统开启减少动画时，日期与镜头立即达到最终姿态。空闲时不重复渲染，不会为帧计数触发 React 每帧更新；只有形状、对象或日期变化才更新阴影图。

## 接口与兼容

```ts
const surface = new BookScene(host, {
  onPageClick: () => {},
  onError: message => {},
  onStateChange: state => {},
});
await surface.setPageTexture(localPngDataUrl);
await surface.setObjects(fragments);
surface.setMode('write');
const rect = surface.getWritingRect();
await surface.flipTo(nextPageDataUrl, { direction: 'next' });
surface.setMode('browse');
surface.resetView();
surface.dispose();
```

保留原 `BookScene` 名称和既有接口，减少数据及集成迁移。`startClosed` 只为接口兼容而保留，不影响默认姿态；`state.open` 始终为 `true`。`open()` 不改变画布，`close()` 只进入空间预览，产品界面不再提供开合封皮按钮。`setCover()` 将合集颜色弱化为底板的微弱色调，不创建或显示封面。

纹理只接受内部 Canvas 或受支持的图片 data URL，不通过远程图床加载。`dispose()` 释放几何、材质、纹理、渲染器、事件和观察器。`ResizeObserver` 适配画布大小，像素比例限制在 2 以下。WebGL 初始化失败或上下文中断时，父级保留普通书写方式和本地记录。

## 实际渲染核验

Canvas 的 `data-renderer`、`data-ready`、`data-mode`、`data-state`、`data-triangles`、`data-frames` 均来自当前 Three.js 实例。只读的 `canvas.__journal3D.inspect()` 保留相机与画布的实际世界矩阵、主面真实顶点范围、日期流转顶点、独立对象网格、帧数和页纹理样本哈希。为兼容旧接口，`coverMatrix` 现在返回浅釉底板的真实矩阵，不能用来推断存在封皮；`turnVertices` 返回单页流转的真实顶点，不能用来推断存在实体书翻页。

`textureHash` 对已解码纹理的 32 × 42 RGBA 样本计算，可核对写入后实际内容变化。绘图缓冲区保留，供浏览器验收读取真实 WebGL 像素。默认无对象场景为 6 个网格、约 2524 个可见三角形，具体读数由渲染器给出，不由测试预设。
