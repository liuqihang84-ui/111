# PNG 导出与册页印刷样式

`exportPagePng(entry, getStickerSrc, { appearance: 'print', bookTitle })` 导出与新版纸页对应的 1280 × 1680 PNG。页面坐标仍为 640 × 840，下载图片按两倍分辨率绘制，编辑控件和选中边框不进入图片。

印刷样式使用纸色 `#FFFEF9`、墨色 `#242624`、朱色 `#BD3E32`、辅助文字色 `#85877F` 和分隔线色 `#DCDDD5`。纸页保持平整，不绘制纸张照片纹理。日期在左上，使用 `YYYY.MM.DD  星期X` 格式；分隔线上保留一小段朱线。空标题、空待办和默认“平静”心情保持留白，已有待办以“小事”为标题。照片使用 8 px 白边及本页日期的小字题注；透明贴纸保留轻微接触阴影。页脚左侧为册名，右侧为月日。

标题从 32 px 缩小以适应一行，最小 18 px，过长时使用省略号。正文使用无衬线字体，从 16 px、30 px 行高调整至 12 px、20 px 行高，保留 180 px 的文字区；超过文字区的行数以省略号结束。完整文字仍保存在 JSON 备份中。

原有两参数调用及 `paperTexture` 选项继续支持旧版纸张样式；只有显式选择 `appearance: 'print'` 才启用新的印刷样式。照片读取、格式校验、尺寸限制与备份验证沿用原有安全逻辑。

开发时用真实 Chromium 验证导出的 PNG：尺寸 1280 × 1680、纸色像素 `(255,254,249,255)`、朱线像素 `(189,62,50,255)`，空标题和待办区域没有额外图案，默认心情位置仍为纸色。旧调用的纸色与心情底色保持原有值。正式浏览器验收另外检查上传照片、透明素材和离线导出的实际像素。
