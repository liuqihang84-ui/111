# 一日手账验证记录

浏览器测试使用本机 Chromium，分别检查桌面 1440×1000 与手机 390×844 的布局和交互。每个用例使用独立浏览器存储，并将所有控制台错误和未捕获异常作为失败；测试不会过滤错误。

## 重现方式

```sh
cd /workspace/111/journal
npm ci
npm run build:portable
# 在另一个终端启动；端口被占用时先确认现有进程的用途。
npm run preview -- --strictPort
npm test
npm run test:browser
```

浏览器配置使用 `/usr/bin/chromium`。预览默认监听 4180 端口；可通过 `BASE_URL` 指向已启动的同一构建。浏览器测试包含单文件 HTML 的离线检查，运行前必须生成 `release/yiri-journal.html`。
