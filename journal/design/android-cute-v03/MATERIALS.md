# 材质规则与可见检查

2026-10-05（北京时间）。以下是拟议视觉规则与 PBR 提示范围，不是物理测量、已选渲染器参数或实际设备验证结果。

## 材质分工

| 对象 | 视觉重点 | 拟议参考与边界 |
| --- | --- | --- |
| 小笺 · 薄软搪胶 | 宽而浅的柔高光，清楚侧面，折角有薄厚关系 | 粗糙度约 0.55–0.70；厚度参考宽度的 5%；避免面部与主体一起油亮、过度鼓胀 |
| 花与云 · 微透树脂 | 薄边透光、内部柔润，花瓣层次与云的薄轮廓可辨 | 粗糙度约 0.25–0.40、透光参考 0.15–0.30；不做玻璃珠或厚糖块 |
| 花芯 / 叶片 | 花芯柔饱满，叶片哑一些、叶脉适量 | 同色系不同粗糙感；不做金属花芯或摄影级叶片细节 |
| 蓝杯 · 细釉光 | 杯口与把手窄高光，内壁暗浅关系、真实空腔感 | 粗糙度约 0.18–0.28；反射集中，避免整杯镜面白斑 |
| 日期便签 · PET 薄片 | 少量透色，窄亮边与轻接触影，印字清楚 | 半透明薄层；不能像厚玻璃牌、果冻或凸起按钮，透光不降低文字可读性 |

粗糙度和透光数值只是沟通材质差别的起点，具体渲染模型会改变结果。最终以近景和界面尺寸下可见的面、边、高光差异判断，不声称这些参数已经真实使用。

## 光与界面

统一左上约 45° 的大面柔光，右侧少量填光；亮边、折角与接触影同向。阴影短、轻、靠近物体，不用四周白光和宽黑阴影制造浮起感。

小笺五官的小亮点、树脂薄边的折光、陶瓷窄高光各自有位置，不能给所有物件使用同一层渐变。微纹理仅在近景隐约出现，缩小后不变成脏点或颗粒噪声。

正文、导航、任务控件与普通按钮使用平面 UI；近景中的厚「完成」按钮只作生成概念示意，界面精稿应改成正常控件厚度。日期标签保持薄片，不延续成一整套厚牌按钮。

## 可见检查标准

- **近景**：无需标签也能分辨搪胶、树脂、釉面和薄片；边缘没有融化，角色轮廓仍与 v02 同源。
- **缩到界面**：约 48–72 dp 的预期素材尺寸仍留少量高光与薄边；不是只有放大后才有质感。这是设计审看目标，尚未验证实际设备尺寸。
- **组合页面**：照片与正文仍占主位，材质重点数量有限；没有所有素材都膨胀、变亮或抢同一处视觉焦点。
- **风格统一**：奶油杏桃与小笺造型保留；光向、圆润程度、阴影和裁切边属于同一系列。
- **后续精稿**：在原生渲染中再核对字体、对比度、系统 insets、触控目标、静态降级和性能；当前图稿不构成这些项目已通过的证据。
