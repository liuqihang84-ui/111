# 一日一笺 · 可爱手账 UI / VI v02

2026-10-05（北京时间） · Android 设计方案 · 本轮先定 UI / VI，尚未实现 App 或生成 APK。

这次围绕用户亲手组织的一页生活设计：日期、计划、照片、便签和贴纸能组合成个人页面。页面是主要内容，书册是入口，界面控件保持清楚。

## 手账的三个用途

| 用途 | 页面结构 | 本方案如何体现 |
| --- | --- | --- |
| 计划型 Planner | 月历、周安排、每日待办，组织未来事情 | 七天周计划、本周小目标、可选时间区域 |
| 记忆拼贴 Scrapbook | 照片、票据、短文字、小物，保留经历 | 自由日页、照片与便签组合、少量贴纸 |
| 方法型 Bullet Journal | 快速记录、索引、专题集合、任务迁移 | 后续可设计符号与专题入口；本轮不承诺完整方法系统 |

用途区别是通用概述；本轮实际查阅的资料与访问限制见 [SOURCES.md](SOURCES.md)。这三种用途可以混合，用户无需同时填满全部模块。

## 页面与拟议编辑体验

- **书册入口**：封面体现个人主题，页面缩略图展示真实编排；没有桌面摆拍和文具陈列。
- **自由日页**：日期、短文字、照片、便签、贴纸各有位置，保留可呼吸的空白；没有照片时不放假相框。
- **七天周计划**：每天安排与本周小目标分别组织；手机上采用可读区块，不把七栏压成微型文字。
- **拟议编排**：点选元素后用原生底部工具栏移动、缩放、轻微旋转和调整层级；提供撤销与可选对齐提示。
- **拟议文字编辑**：正常大小输入、系统键盘、清楚保存状态；文字与布置可切换，键盘出现时读取真实 IME insets。
- **拟议素材选择**：照片、便签、贴纸各自有入口，收藏常用素材；装饰能够删除，不盖住正文。

以上交互是设计意图，尚未编码、保存真实记录或在 Android 设备验证。

## 一套奶油杏桃的可爱质感

主背景为奶油白，文字为清楚的可可色，杏桃承担主要行动；浅蓝和嫩绿只用于少量标签与素材变化。常规界面保持平面、干净，触控目标设计至少 48 dp；正文拟用 Android 中文 sans / Noto Sans SC 16 sp，尊重系统字体缩放。

原创「小笺精灵」由圆角便笺、折角和两点眼构成，建立固定轮廓、眼距与少量表情。它出现在贴纸、空态和必要反馈中；普通操作图标继续表达熟悉语义，不全部变成角色脸。

贴纸用统一裁切边、薄微凸层次和极轻阴影；便签用平滑色面与小折角，胶带体现少量半透。光线方向一致，单页只有少数材质重点，不使用厚重立体按钮、摄影纸纹或满屏漂浮形体。可爱来自造型、配色和内容关系，素材属于同一系列。
