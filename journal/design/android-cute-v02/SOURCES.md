# 手账研究来源

2026-10-05（北京时间）。以下是本轮实际读取的公开资料，结构观察与本产品的设计建议分别说明。外部照片仅作研究，未复制到本设计交付库。

| 已查阅来源 | 实际看到的内容 | 对本方案的启发 |
| --- | --- | --- |
| [memori · 作者说明](https://github.com/hunterirving/memori/blob/main/readme.md) | 将照片按格纸尺寸布局，移动、缩放、裁切、旋转、多选，打印后剪裁粘贴；团队参考了文档中的 `spread.jpg` 与 `juneyo.jpg` 实物页 | 手账内容具有个人编排；照片与短文字共同构成页面，不只有顺序列表 |
| [remarkable-calendar · 作者说明](https://github.com/elainajones/remarkable-calendar) | 月历、24 小时日程格、习惯记录与分区跳转；团队参考了月页与日页示例 | 时间结构为计划型页面提供骨架；本方案不直接移植其 PDF 或预填事项 |
| [The Met · Blemly 剪贴簿](https://www.metmuseum.org/art/collection/search/591861) | 馆藏说明实际收集报刊剪片、名片、速写、画作照片与目录 | 手账可组织经历中的不同材料，而不局限于文字日记 |
| [The Met · Valentine makers’ scrapbook](https://www.metmuseum.org/art/collection/search/894304) | 馆藏记录剪纸、墨、水彩、彩色印刷与装饰碎片 | 研究拼贴的层级和材料组合；不照搬历史纹样或宣称复原 |
| [Butterfly · 项目说明](https://github.com/LinwoodDev/Butterfly/blob/develop/README.md) | 混合手写、文字、图片；元素可移动、缩放、重排；模板、图层与可复用组件；并实际读取其 select、stamp、templates 文档 | 为自由日页、素材选择与可编辑页面提供工具参照；本轮未引入其代码或素材 |

memori 明示是独立非官方工具，与 Hobonichi 无隶属、背书或赞助关系。remarkable-calendar 是创作者的独立 PDF 项目，其说明称受 Hobonichi 启发；两者不能替代 Hobonichi 官方产品研究，也不是本 App 的实现方案。

本轮尝试访问 Hobonichi、Bullet Journal 与 TRAVELER’S COMPANY 官方站，均被当前云环境代理以域名限制 / 403 拒绝。没有绕过访问限制，也不声称已读这些官方内容。Bullet Journal 的方法概述属于通用知识，尚未通过其官网本轮核对。

奶油杏桃配色、原创小笺精灵、书册入口与 Android 页面安排是本项目的设计推导，不是上述资料给出的原话或既有产品效果。图稿中的生成示例与外部研究照片应分别标明来源；原生字体、无障碍、性能及数据行为需后续实际验证。
