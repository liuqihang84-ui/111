# 一日一笺 · 梦游纸片 v05

2026-10-05（北京时间） · 新风格 UI / VI 提案 · design-only，未实现 Android App 或生成 APK。

这次同时改变造型、构图、素材和颜色：清楚折面的几何纸片精灵、钴蓝与柠檬黄、数字刊物式书册、内容里的不对称大标题。电子手账仍用于组织自己的日子；页面内容占主位，避免把日页做成固定宣传海报。

## 三个页面

- **手账入口**：薄而轻的数字刊物封面、真实页面缩略图与清楚的新建入口；不沿用厚软封面。
- **自由日页编辑**：照片、文字、日期票签、小事和几何贴纸可拟议编排，大标题属于用户内容；操作栏对齐，不随内容倾斜。
- **几何素材选择**：折片、折星、半月、票签、蓝弧、透明框形成一套；主稿用三列网格，正式布局可随窗口与字体调整，不强制两列。

花、杯、奶油膨胀形体与七卡周页不进入这轮素材体系。新精灵的折面与轮廓只是 **proposed**，尚未建立用户批准的 canonical 造型。

## 材质、排版与拟议操作

缎面折片表现清楚面转折；树脂 / PET 票签保持薄、少量半透，素材共享左上柔光。材质只用于贴纸与票签，正文、导航、按钮和常规容器保持平面。

底部导航为「手账 / 素材 / 我的」。编辑工具为「文字 / 照片 / 贴纸 / 布局」，选中元素后提供「旋转 / 图层 / 删除」。文字输入拟使用系统键盘与真实 IME insets，不制作假键盘。

正文 16 sp、实际触控目标至少 48 dp、常规横边距 24 dp 是**拟定规则**，不是图片尺寸测量或设备验收；系统字体缩放与布局须后续验证。用户照片保留自己的颜色，不强制变蓝或套统一滤镜。

| --- | ---: |

主按钮用蓝底、暖白字，黄色标签用墨字。黄色在暖白上不能单独表达必要焦点、选中或警告；使用墨色 / 蓝色边界、符号及非颜色语义。数值仅是 nominal 色对公式计算，不代表生成图像素或设备对比度已验证；详见 [design-tokens.json](design-tokens.json)。
