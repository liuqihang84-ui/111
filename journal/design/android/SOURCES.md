# 设计来源

- 总览与状态板由图像生成工具制作，并根据同一设计方向进行参考图修订。原始图片保留，交付文件为直接复制，未裁切成组件或改写像素。
- 风景、日记文字和小事均为设计示例，不是用户记录、个人摄影或历史绘画复原。正式首次使用的空态不生成示例记录。
- 「折光弧」SVG、图标、页面与组件源稿是本轮编写的向量设计。品牌轮廓以 `brand-mark.svg` 为准，生成图的透视和折射不能替代规范母形。
- 本方案以留白、方圆和虚实的关系转译现代东方审美，不宣称复原某件古代玉器或某朝代界面。
- 文本 SVG 和 JSON 指定 Android 中文无衬线字体；品牌与少数短标题可延续 Guanwu Serif。设计包不附第三方字体二进制。正式使用新增字体时，记录实际字体与相应许可。
- 原生系统栏、键盘和触控区域在概念图中仅是布局示意。本包不含 App、APK、系统键盘实现或设备测试结果。

具体图片来源与 SHA-256 见 `image-provenance.json`。
