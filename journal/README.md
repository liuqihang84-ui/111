# 一日一笺 · 浮笺

版本 `0.6.0`：以「温玉 × 苍墨」重整电子手账的视觉。日期成为独立的导航锚点，标题与正文位于一张圆角数字画布，短操作区集中常用入口；暖白、深青和薄玉材质贯穿界面与素材。「记录 / 收藏 / 日历」用于编辑、合集管理与回看，制作工具按需展开。

「空间预览」把同一页的内容呈现为略有高度差的薄片与轻弧面，可以拖动查看图层角度；「继续书写」返回原生编辑。切换日期使用轻缓的流转。已有浏览器记录与 JSON 备份继续兼容。

## 记录与摆放

- 直接编辑标题和多行随笔，按日期保存，支持待办与当日心情。
- 工具条提供撤销、重做与「加内容」，加入新的浮笺装饰或照片后，可拖动、缩放、旋转、复制、调整前后顺序与删除。
- 上传 PNG、JPEG 或 WebP 照片，单张最大 15 MB。照片在浏览器内缩小后保存，不上传服务器。
- 「收藏」以合集面板管理手账名称与视觉主题；「日历」用于回看与切换日期。
- 「更多操作」提供当前页面 PNG 导出和全部手账的 JSON 备份、恢复入口。

新的八件薄玉素材为玉题签、玉界框、清流线、薄玉弧、玉索引、轻折片、玉叠片与玉朱点，提供题签、框界、线条和层次的编排形式。上一版八件光片收进「浮笺旧藏」，八件纸品保留在「印刷旧藏」，更早的十二件小物保留在「旧藏」。资源 ID 和已保存对象保持兼容，不清空既有记录。

编辑使用原生输入区，保留正常的中文输入、选择与键盘操作。可选空间预览使用 WebGL 2；不可用时显示状态并继续书写、保存与导出。系统的减少动态效果偏好保留全部功能，减少过渡运动。

## 本地数据

内容自动保存在当前浏览器的 `localStorage`，无需账号或 API 密钥。存储不可用或空间不足时，页面会提示并提供备份入口。应用没有云端同步。

PNG 导出为 `1280 × 1680` 的页面图片，适合分享；JSON 保存可恢复编辑的全部手账。导入 JSON 先验证格式，覆盖前先下载当前内容的备份；无效备份不会替换当前手账。

不同浏览器、隐私窗口、网站地址和本地文件路径可能使用不同存储空间。移动文件、切换访问方式或清理浏览器数据前，请导出 JSON。

## 安装与启动

需要 Node.js 20.19+、22.12+ 或更新的受支持版本，以及 Python 3。Python 只使用标准库打包 ZIP。

在此目录运行：

```sh
npm ci
npm test
npm run build:portable
PORT=4180 bash tools/serve.sh preview
```

开发模式使用 `npm run dev`；生产预览可使用 `npm run preview`。需要严格固定端口时，使用 `PORT=4180 bash tools/serve.sh dev` 或 `preview`。启动脚本监听 `0.0.0.0`，端口占用时明确失败；生产预览要求已生成 `dist/`。

依赖锁定包含 `three@0.180.0`，开发类型为 `@types/three@0.180.0`。空间预览的薄片、轻弧面、材质与光照由代码创建；常规安装与启动不下载外部模型，不需要生成图片或调用 AI API。

浏览器验收使用 `BASE_URL=http://127.0.0.1:4180 npm run test:browser`。本轮执行范围与实际结果以 [QA.md](docs/QA.md) 和生成的报告为准，旧版本通过结果不代替新版验证。三维实现与检查接口见 [3D-ENGINE.md](docs/3D-ENGINE.md)。

## 离线与源码交付

`npm run build:portable` 生成：

- `dist/`：静态生产构建。
- `release/yiri-journal.html`：内嵌脚本、CSS、美术和字体的离线单文件。
- `release/yiri-journal.zip`：单文件 HTML、中文使用说明和完整许可证说明。
- `release/release-manifest.json`：文件大小、SHA-256、资源检查与 ZIP CRC 记录。

将 ZIP 完整解压后，用现代 Chrome、Edge 或 Firefox 打开 HTML。Three.js、材质与页面内容都在本地运行；记录、空间预览与导出无需网络。构建会拒绝残留的外部加载资源，并校验压缩包中每个文件的 CRC 和实际字节。托管环境如限制本地文件访问，应保留策略，以允许的 HTTP 载入完全相同的 HTML 字节再断网验证；实际方法与限制写入 QA 记录。

独立源码包使用：

```sh
python3 tools/package-source.py
```

输出 `release/yiri-journal-source.zip`，解压后的 `journal/` 可独立执行上述安装命令。源码包包含源文件、测试、配置、锁文件、文档和本地美术，排除依赖目录与生成输出；打包脚本核对 ZIP 文件名、CRC 和源码字节，并生成 `release/source-manifest.json`。

## 美术、字体与保留项目

浮笺采用现代东方的数字画布与分层空间。背景 `#E8EBE4`、暖白 `#FCFBF6`、苍墨 `#183B35`、玉青 `#536F63` 与少量陶朱 `#BC745E` 构成调色板；字标保持「一日一笺」。日期侧栏、书写画布与常用操作通过位置和明度建立层级，薄玉素材以轻薄边缘与温润受光提供空间感。当前记录生成页面内容，照片和装饰各自形成有浅高度的独立薄片；材质、柔和光照与流转由浏览器实时计算。场景来自本地代码、图像与当前手账内容，无外部 GLTF 或在线材质依赖。

新的八件薄玉素材由 image_gen 为本项目生成。来源、实际提示词、尺寸、哈希与透明检查见 [JADE-ART.md](docs/JADE-ART.md)，统一 UI / VI 见 [VISUAL-IDENTITY.md](docs/VISUAL-IDENTITY.md)，完整来源见 [ART-SOURCES.md](docs/ART-SOURCES.md)。旧浮笺图集记录保留在 [FLOAT-ART.md](docs/FLOAT-ART.md)，旧印刷图形与材质的生成记录继续保留在 [PRINT-ART.md](docs/PRINT-ART.md) 和 [TACTILE-ART.md](docs/TACTILE-ART.md)。

应用内嵌 Guanwu Serif，为 Noto Serif SC 的重命名衍生子集。软件和字体版权声明及许可证全文见 [NOTICES.txt](docs/NOTICES.txt)，其中保留实际分发的 Three.js MIT 许可证。
