# 观物交付与运行说明

## 交付目标

首轮交付包含一个可直接打开的交互网页，以及可用于正式静态站托管的构建目录。网页同时承担美学研究与制作辅助，不把某个游戏类型作为前提。

页面不连接 AI 模型 API；生成的制作简报、素材规格与色板用于协助用户在自己选择的工具中制作。项目使用浏览器本地存储，本版本没有云端项目保存服务。

## 可下载的离线文件

运行 `npm run build:portable` 后，下载入口应指向：

| 文件 | 用途 |
| --- | --- |
| `release/guanwu-art-workbench.html` | 双击打开的单文件网页 |
| `release/guanwu-art-workbench.zip` | HTML、README.txt 与 NOTICES.txt |
| `release/release-manifest.json` | 大小、SHA-256 与打包检查记录 |

ZIP 解压后，用现代 Chrome、Edge 或 Firefox 打开 HTML。脚本、样式与研究图须内嵌；博物馆和参考资料链接需要网络。这些外部链接的可访问性不影响离线工具运行。

本地保存依赖浏览器的 `localStorage`。浏览器、隐私模式或文件路径变化可能改变存储空间；用户应保留项目导出副本。不要把本地保存描述为云端账户同步。

## 构建与交付检查

交付脚本使用仓库内的 Vite 重新构建单文件页面，检查文档的加载资源、内联 CSS 的 `url()`、脚本中残留的图片及字体路径，复制通过检查的 HTML，再生成 ZIP、进行 CRC 校验并计算 SHA-256。

### 每次交付的验收范围

静态检查与 ZIP 完整性检查不能替代浏览器验收。每次交付还应验证：

1. `npm run build` 正常完成，类型检查通过。
2. 项目逻辑测试与浏览器检查按实际实现执行。
3. 在允许本地文件访问的浏览器中使用 `file://` 打开交付 HTML；若所在环境的策略阻止访问，记录限制，并验证经 HTTP 载入的相同交付 HTML，不把替代检查写成本地文件模式通过。
4. 断开网络或阻止外部请求后，核心页面功能继续工作。
5. 创建、保存、重新加载和导出项目，确认数据与界面一致。
6. 浏览器控制台没有未处理的异常，交付包内含实际软件许可证与美术来源说明。

上述内容是验收范围；已完成的结果以上表为准。具体结果应记录运行命令、输出文件和限制；尚未运行的检查不得写成“通过”。浏览器测试报告路径为 `test-results/browser-report.json`。

## 云环境启动

首次安装依赖：

```sh
cd /workspace/111/art-workbench
npm ci
```

开发模式：

```sh
PORT=4173 bash tools/serve.sh dev
```

生产模式：

```sh
npm run build
PORT=4173 bash tools/serve.sh preview
```

启动脚本监听 `0.0.0.0`，要求指定端口可用。页面访问地址使用云环境实际提供的入口，不能把个人电脑上的 localhost 当作远程用户可访问的链接。

当前 Playwright 配置使用 `/usr/bin/chromium`。在其他环境运行测试时，可把 `playwright.config.ts` 的 `executablePath` 设置为该环境已有且可用的浏览器路径，或采用对应的 Playwright 浏览器。浏览器管理策略应保持有效；本项目不提供绕过策略的步骤。

## 源码与下载文件交付

离线 HTML/ZIP、源码和文档可以放在独立交付分支，便于下载与后续修改。此类文件交付不需要启用 GitHub Pages，也不代表已有公开网站。远端写入范围遵循用户在当前会话中的授权，常规可逆的源码交付与正式公开上线分别处理。

## 正式静态站上线

`dist/` 是常规静态站文件，可用于 GitHub Pages、其他静态托管服务或已有 Web 服务器。构建采用相对资源路径，适合仓库子路径；正式域名仍需检查直接访问、资源加载和移动端布局。

用户尚未明确授权正式上线时，先提供可验证的 HTML/ZIP、源码与部署说明。不要自行启用 GitHub Pages、修改站点发布配置或部署到第三方服务。收到明确上线授权后，再根据选定的域名和托管方式完成发布并验证实际地址。

## 引用与美术来源

`reference` 与 `verified` 是研究资料核对状态，不能代替版权许可。网页中的数字色板与示意图属于现代转译，不能称为古代颜料测量、文物复原或历史服饰考证结果。美术来源的具体说明见 [ART-SOURCES.md](ART-SOURCES.md)，打包时该说明会加入 `NOTICES.txt`。

博物馆或文献网站可能受网络策略影响；保留准确的链接、核对范围和限制。没有独立授权的馆藏图像不应因为出现在来源列表中就被打包再分发。
