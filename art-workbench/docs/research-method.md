# 观物：研究依据与美术转译方法

本工作台同时支持研究和制作。它不把“中国古代美学”视为一个可以套在任意产品上的滤镜，而是从具体时期、对象、媒介与使用场景中提炼形式，再将形式转成可审核的现代美术规范。游戏类型尚未确定，以下路线不要求沿用旧游戏的世界观、人物或玩法。

## 先读清楚三种信息

| 层次 | 本工作台怎样使用 | 不能声称什么 |
| --- | --- | --- |
| 历史依据 | 有名称的作品、器物、典籍、洞窟或馆藏检索线索；记录作者、时期、媒介及不确定归属 | 一个现代概念图能够证明古代原貌；一个传统归属已得到确定 |
| 研究解释 | 根据具体作品观察构图、线条、尺度、题材与材料；明确这是分析与取舍 | 一个作品的特征等于整个朝代或“中国审美”的唯一原则 |
| 现代转译 | 将观察写成资产、界面、输出与一致性约束；采用现代色值、组件与可访问性规则 | 现代 design token、PBR 参数、AI 提示词就是古代画论或历史工艺 |

当前资料状态为 **研究线索（reference）**。它表示已经写明可查对象和检索入口，不表示本环境已成功读取对应网页、逐件核对馆藏记录或取得图片使用许可。当前没有任何来源被标为已核验，也没有填写虚构的访问日期。

部分博物馆域名此前在云环境中返回访问限制。研究数据保留官方入口，并说明应搜索的作品或关键词；不通过镜像、代理绕过限制，不虚构精确馆藏 ID。读者打开这些链接后，应继续进入馆方对应条目，而非把首页当成具体作品的证据。

## 配图与配色的边界

当前两张研究板来自项目已制作的原创形式示意，分别为山水三联和人物器物三联；它们 **不是馆藏图、史料图、考据复原图或对 12 条路线逐条完成的成果图**。界面借用这些图的局部帮助理解形式，不能据此认定宋瓷、明式木作或元明青花已有准确的专项配图。下一轮应为每条选定路线单独建立来源索引、结构草图和原创实验板。

各路线的 5 个十六进制色值都是 **现代屏幕参考色**，用于建立背景、线条、焦点和辅助层级。它们不是石青、石绿、朱砂等颜料的物理测量值，也不是汝窑釉色、青花钴料或壁画初绘状态的数字复原。旧作照片受保存状态、照明、扫描和白平衡影响；直接吸取截图颜色，不会自动得到历史准确的颜料配方。

配色也不是必须同屏使用的五种颜色。例如宋瓷路线中的青釉、白瓷、黑釉是不同窑系的比较入口：生产时先选择一个主窑系，不能默认把三者随机混进一套器物。

## 12 条路线的研究问题

### 1. 汉代朱黑漆器：色是怎样依附器形的

主要线索是马王堆一号汉墓出土漆器，以及“君幸食”“君幸酒”等器上题字。研究单位应为一件具体盘、杯或盒，而不是一个“汉代红黑”拼贴板。先记录用途、胎体、口沿、内外壁、足部与装饰位置，再比较朱黑如何分配。不同漆器可能使用木胎、夹纻胎等，不能一律称木器。

现代转译先建立外壳、内腔与边缘的分区，纹饰随曲面转折。在深色 UI 中，朱色承担少数关键动作，正文另用高对比浅色；游戏道具先看口沿、把持和接触点，再添加云气线。漆面反射要含蓄，避免统一镜面把漆器做成塑料。

### 2. 汉代画像石：动作怎样在有限深度里可读

山东汉画像石、嘉祥武氏祠，以及成都出土《弋射收获画像砖》提供不同对象的比较。石刻和模印砖不是相同媒介；祠堂、墓葬和不同区域也不具有完全一致的图像功能。武氏祠相关叙事涉及历史、伦理、祥瑞与神话，引用人物或题材前需要核对原语境。

现代转译可取侧面行动、轮廓工具、层带叙事和清晰事件分区。先做无纹理剪影，检查重心、肢体和工具能否表达行为，再选择一种刻线规则。拓片与石面实际颜色分开，不通过满屏裂纹“增加历史感”。

### 3. 青绿山水：从整卷组织学空间，不只学蓝绿

《千里江山图》是有明确作者与年代线索的主样本；《江帆楼阁图》须使用“传李思训”的谨慎标注，并继续核对馆方归属说明。《林泉高致·山水训》提供三远与观看关系的画论入口。

研究整卷山势、峰谷、岸线、桥舟、村落与人物尺度，记录密集段、开阔段和连接路径。现代游戏先把它转成灰阶空间骨架、可走路线、遮挡与显露，再分配青绿。三远不是三个相机预设，矿物色感不是自发光。现代界面可借山势层级，但正文与交互仍需安静底面。

### 4. 南宋小景：空白怎样与物象发生关系

马远《山径春行图》《水图》与夏圭《溪山清远图》提供小景、册页和连续手卷的不同例子。“马一角、夏半边”不能概括两位画家全部作品；宋代也不是全水墨、全灰色、无装饰的统一风格。

逐件观察枝、岸、人物视线与开放水面的呼应。现代转译将每屏分成主体、引导形与开放区，留白承担具体的水、天、雾或使用空间。近密远疏可以成为镜头节奏，但不以雾化掩盖结构，也不把所有页面固定成左下角一棵树。

### 5. 宋代工笔花鸟：精细如何服从生物结构

崔白《双喜图》、赵佶《瑞鹤图》与匿名《出水芙蓉图》既有不同物象，也有不同题材和叙事语境。不能给匿名画补造作者，也不能把祥瑞画直接解释成纯自然写生。

先记录物种、季节、叶序、花型、鸟喙、体态与叠压关系，再看线色。现代角色装饰或图鉴可以细致，但需要确定主线、结构线与细节线，并提供缩小版本。假花、错叶序、没有起点的羽翼不能靠“工笔质感”掩盖；幻想变化则明确标成原创设定。

### 6. 宋代瓷器：用比较防止“宋代等于极简”的误读

汝窑无纹水仙盆、定窑白瓷与建窑黑釉盏说明同一时代具有多种器形、装饰和表面。汝窑不等于所有天青色瓷器，宋瓷也不只汝窑；开片并非所有宋瓷都有。

先选主窑系与具体器物，画出口沿、肩腹、足部和壁厚，再研究釉层与高光。现代 UI 可转译为连续曲率和温和层次，但浅底文字不能浅到不可读；现代 3D 则需要分别处理胎体、釉面与未施釉足部，不只是换颜色。

### 7. 敦煌壁画：必须先分期、定位与辨题材

建议以莫高窟第 254 窟（北魏）、第 172 窟（盛唐）、第 85 窟（晚唐）建立三个对照索引。每个索引继续记录壁面位置、图像名称、人物身份、建筑关系、边饰和保存状态。这三个样本不是穷尽敦煌，也不能将其全部装饰、服饰和人物比例合并成一种“敦煌风”。

佛、菩萨、供养人、飞天与经变、本生等题材不能任意互换。游戏或 App 未完成题材核对时，优先借线色秩序、群像层次和抽象边饰，不把宗教主体直接变成敌人、促销符号或滑稽头像。保护研究中的变色、剥落、现状照片与研究复原分别归档，不将今日壁画色直接宣称为初绘色。

### 8. 文人园林：设计视点与使用，而非堆装饰

《园冶》提供营造和因借的研究线索，《长物志》提供特定文人阶层的陈设品评；后者不能被当作所有中国古人的生活规范。拙政园、留园等现存空间经过改造与修整，今貌不能无说明地标成初建原貌。

以人的路径和停留为顺序，记录当前所见、遮挡与下一处显露。门窗与框中景有前后深度，水石植物都有尺度。游戏同时验证视点、碰撞和可达性，App 借层级而不强行制造迂回导航；少走弯路也可以保有节奏。

### 9. 明末彩色木版：工序比旧纸滤镜更重要

《十竹斋书画谱》《十竹斋笺谱》《萝轩变古笺谱》是主要入口，具体扫描必须核对版本。饾版、普通套色与拱花应分别理解：分版印色和纸面压凸并非一个“错版”特效。作为后续传播比较的《芥子园画传》初集初刊于清代，不能标成明末作品。

现代资产将主线、局部色版、纸底和压凸示意分开；设定色层数量、线宽和透明导出规则。套印偏移是可选现代处理，并非古版必定粗糙。关键文字、图标边界和小尺寸资产不应被偏移破坏。

### 10. 明式木作：结构不是装饰的附件

圈椅、四出头官帽椅与《长物志》的几榻描述提供起点。明式是类型和风格概念，具体实物制造年代需逐件核对；不能将所有明式家具都标成明代原作。木种也不能由屏幕中的褐色来鉴定。

先检查承重、重心、构件、连接、人体尺度与曲线用途。正侧背视须是同一结构，木纹随构件方向。AI 概念图不等于可以加工的榫卯工程图；图中看不见或不成立的连接必须列为未验证，而不是通过高光美化。

### 11. 书法与版式：借行气，不能制造假文字

《寒食帖》《松风阁诗帖》是墨迹研究入口，《雁塔圣教序》拓本是碑刻与传本比较入口。正文、题跋、鉴藏印、装裱可能来自不同时期；原碑年代与某一拓本年代也不是同一信息。

可分析字行尺度、疏密、主次和题跋关系，再转成现代排版。菜单、正文、数值与按钮必须由真实文本渲染；AI 画出的假字不可交付。标题书写需核对字形与字体许可，印章不伪造作者、古文、年代或认证。竖排是专项组件选择，需要阅读顺序和键盘验证，不是普遍强制规则。

### 12. 元明青花：分型先于蓝白滤镜

1351 年铭文大维德瓶、明永乐青花压手杯与明宣德青花样本应分组研究。它们不仅时代不同，也具有不同器类、尺寸、用途与装饰区。不能用“元浓明淡”概括全部，也不能凭斑点判断年代或钴料来源；晚明的另一些体系应另外建立样本。

先画器颈、肩、腹、足和主纹、边饰、白地的关系，再处理釉下线、填色、轻染和表面反射。现代 UI 保留白地阅读区，青花纹样只进入少量明确区块；现代跨期组合须标注为原创转译，而非历史复原。

## 从研究到可生成的美术规范

一个可靠的制作流程应留下以下可追踪结果，而不是只保存最后一段提示词。

1. **确定问题。** 写明要解决角色轮廓、场景层次、图标辨识、UI 统一或其他具体问题。玩法和产品功能未知时，不自行固定游戏类型。
2. **建立单一主样本。** 选择一个时期、一个媒介和 1–3 件具体参考，记录来源状态和不确定点。其他样本只作比较。
3. **拆解结构。** 用灰阶、轮廓或线稿记录构图、尺度、视角、形体、材料和使用区域；不先追求装饰。
4. **设定生产锁。** 固定比例、主色区、线宽、视角、光源、材质、锚点和输出规则。把可变化项与不能变化项写成两列。
5. **做小批实验。** 先生成同一对象的 3 个变体，而非同时生成一百个资产。只改变一个主要变量，检查哪条约束容易失效。
6. **分层修正。** 先修结构，再修色区，再修细节。正文、逻辑、碰撞、真实数据和图像分离。
7. **放回实际尺度。** 游戏放回实际镜头，App 放回窄屏、长文本、键盘与不同状态。展示大图好看并不证明最终可用。
8. **归档与导出。** 保存设定、来源索引、提示词、版本、尺寸、许可状态与审核结果。实际图片生成取决于使用者选择的模型和工具，本网页不会凭空声称完成未运行的生成。

### 游戏资产至少锁定什么

| 资产 | 需要锁定 | 交付检查 |
| --- | --- | --- |
| 角色 | 身高与头身比、正侧背关系、服装层次、色区、装备数量和位置、动作朝向、足部锚点 | 同角色各视角与动作一致；手脚、工具、支撑点成立；透明边缘无底色；实际镜头可辨 |
| 场景 | 可走空间、主地标、前中后层级、相机规则、光源、素材尺度与拼接规则 | 路线不被装饰隐藏；背景不吞没角色；重复贴图不形成明显机械格；遮挡与碰撞一致 |
| 道具 | 用途、器型、接触面、材料层、尺度、视角、光源 | 灰阶轮廓可辨；结构成立；与手或地面接触合理；远近预览均清楚 |
| 图标 | 一致画布、视角、光源、轮廓占比、线宽与留边 | 16/24/32/64 像素预览；同状态语法；去色后仍可辨；不烘焙不需要的纸底 |

上述像素大小是现代示例，生产时按项目实际尺寸调整；它们不对应任何历史画幅规范。

### App 美术至少锁定什么

| 层级 | 需要锁定 | 交付检查 |
| --- | --- | --- |
| 基础 token | 语义颜色、字体授权、字号、行高、间距、曲率、边框与阴影 | 正文与背景的实际对比、字号、缩放及高对比模式；不将色彩作为唯一信息 |
| 组件 | 默认、悬停、焦点、按下、禁用、加载、错误与成功状态 | 状态互相可辨；文本长度变化不过界；键盘焦点明确；按钮语义正确 |
| 插画 | 主线、色层、视角、光源、留白、背景归属与透明导出 | 不遮盖内容；手机裁切仍保留主体；同套颜色和尺度一致；必要文本另排 |
| 页面 | 研究、制作与导出的路径，内容密度与响应式规则 | 窄屏、长文本、空状态、错误状态可用；读屏顺序与实际操作顺序一致 |

对比度等验收属于现代可访问性实践，不是以古代作品照片为标准。真实值须由最终 UI 的实际前景、背景与字号计算；仅提供一组漂亮 palette 不代表通过可访问性检查。

## 示例：把“青绿山水”从口号改成约束

不充分的指令：“中国古风，青绿山水，精致，8K，游戏背景。”

可审核的工作说明应补足：以北宋青绿手卷为空间研究依据；原创渡口场所；主峰、近岸、水面与赭色路分别承担深度、生活尺度、开放区与可走路线；光源与相机固定；人物、舟、屋门的尺度关系固定；可交互物的轮廓和明度与背景分离；不要直接复制馆藏局部；导出尺寸与透明规则由实际项目确定。

检查重点是路径、尺度、层次与可用性，而不只是画面是否“够古风”。若此说明仍不能稳定生成同一座桥、同一角色和同一套 UI，就要进一步建立参照图、结构草图与批量参数，不能仅追加形容词。

## 来源核验与使用许可

后续核验一条来源时，至少记录具体页面、访问日期、作品名、时期、媒介、归属表述、图片类型与许可说明。只有实际打开和核对后才可将 `status` 改为 `verified`，不能因链接可点击就标核验通过。

历史作品、馆藏摄影、扫描、数字复原和现代临摹应分别判断许可。古代作品年代久远，不代表所有博物馆数字图片都可无条件商业使用。当前工作台只提供研究线索和原创示意，不将馆藏图片打包成商业素材。用户之后如要直接使用某张图，应以具体馆方许可与目标发行地区的适用规则为准。

这些边界是为了让原创资产知道自己借鉴了什么、修改了什么、还有什么未确认。它们不妨碍现代创作；它们防止把现代创作包装成未经验证的历史事实。
