# 素材库验收记录

素材文件与美术参考板分开计算：192 个 SVG 源文件是可编辑的单幅素材；10 张 PNG 是完整参考板，其内部图格没有被计作独立资产。

## 数据与实际文件

- 素材分类：60 个图标、32 个纹样、24 个边框、24 个材质图形、16 个界面布局图形、20 个器物插画、16 个场景插画。
- 所有 48 条美学研究路线都关联至少一个实际 SVG；没有孤立或无效的路线 ID。
- 192 个资产具有不同的空间图形或材质光照结构。比较忽略名称、ID、颜色和单纯的线宽变化，保留路径坐标、形状、变换、渐变方向与停靠位置等实际绘制定义。渐变定义不同的材质不会被误判为同一个轮廓的换色。
- SVG 不含脚本、外部图片、外部字体或远程资源引用，实际文件尺寸与声明的画布一致。
- 素材 ZIP 按实际文件逐项核对：中央目录、本地头、文件大小、独立重新计算的 CRC，以及 SVG 与源文件的字节等价性。筛选或选中导出只包含对应集合；重复 ID 去重，空集合及不安全文件名被拒绝。

2026 年 10 月 4 日（Asia/Shanghai）的最终验收：全部 27 项单元测试通过，其中本次新增素材验收 8 项；全部 22 项浏览器验收通过，用时 56.1 秒，没有跳过、意外失败或重试后通过的项目。浏览器验收记录中的 JavaScript 异常及控制台错误均为空。

## 平铺像素检查

使用系统 Chromium 将所有 48 个标记可平铺的 SVG 实际解码到 Canvas，比较两侧边缘的预乘 RGBA 像素与普通相邻像素的变化。检查中发现并修复了回云、缂丝云线、珐琅扇纹和朱漆斑纹的边缘截断；修复后的全部 48 项通过明显边界跳变检查。

这项检查容许连续斜线和抗锯齿的正常像素差异，不声称两侧采样点完全相同，也不替代项目中实际尺寸、配色及密度的人工检查。界面纹样请在真实显示比例下查看重复预览。

## 浏览器功能覆盖

`tests/materials.spec.ts` 包含 9 项独立浏览器验收：

1. 实际渲染 192 个 SVG，逐条操作 48 条路线筛选，以及分类、家族、游戏/App、透明和平铺筛选。
2. 收藏与选中素材在刷新后保留，原生详情窗口可用 Escape 关闭并恢复焦点。
3. SVG 下载为真实可解析向量文件；选择 PNG 导出尺寸后核对 PNG 签名、IHDR、浏览器实际解码尺寸、透明像素及非空绘制。
4. 对全部平铺素材检查实际像素，确认平铺开关改变实际预览绘制。
5. 选中及筛选 ZIP 的实际集合、清单、CRC 和 SVG 内容一致。
6. 10 张美术参考板实际显示，并逐一下载 PNG 与对应原文件字节比较。
7. 保留游戏/App 方向与选定研究路线，将素材带入制作台，在编辑、项目保存、导出及恢复后保持出处参数。
8. 390 像素屏幕下检查筛选、图库和原生详情窗口无横向溢出。
9. 在字节完全相同的单文件包中断网，操作筛选并下载 SVG、PNG、ZIP 与整张参考板，确认没有请求外部 HTTP(S) 资源。

新增 9 项素材浏览器验收全部通过。完整执行结果与截图在最终 `verification/browser-report.json` 和 `preview/` 中记录。单文件的断网检查经允许的 HTTP 加载同一份 HTML 后执行；受管理 Chromium 策略限制，本环境的 `file://` 加载不作为通过项目。

约 44 MB 的单文件 HTML 超过 Chromium 调试协议默认的响应捕获缓存。验收只扩大同一 CDP 会话的调试缓存，读取浏览器真实收到的文档响应并与交付文件逐字节比较；没有伪造网络响应或更改浏览器访问策略。该调整仅用于验证，不是运行网页所需的配置。
